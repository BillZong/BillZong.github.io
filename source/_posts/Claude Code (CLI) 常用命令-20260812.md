记录 Claude code (cli) 中的一些最常用的命令。

- `shift + tab` 自动接受编辑
- `#` 创建一个记忆
- `!` 进入 bash 模式
- `@` 添加一个文件、目录到上下文
- `esc` 取消
- `两次esc` 跳回到历史中，`--resume` 对历史进行回复
- `ctrl + r` 展开更详细的输出
- `vibe` 进入 vibe coding 模式
