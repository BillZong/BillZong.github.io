04 链表 ​

链表没有随机访问，所有解法都在跟「定位成本」搏斗。 适合：给 head 要反转、断链、合并、倒数第 k 个。

1. 场景 ​

题面给出一个头节点和节点结构，链表长度动辄 5×10^4，没有下标可用。决定性条件通常藏在一句话里：只许改指针不许改值（0143）、要求一趟完成（0019）、要求拼接原节点而不是复制（0021）。

认出信号：出现 head / ListNode；要求反转、合并、删除倒数第 k 个、交错重排。这类题几乎不考算法，考的是指针的先后顺序：每改一个 next 之前，先想清楚谁还指向前驱。

2. 核心机制 ​

链表的节点是不可分割的原子，能动的只有 next 指针。插入删除本身是 O(1)，但「找到第 k 个节点」是 O(n)——链表的全部困难都来自定位。

于是链表套路都是同一个转换：把「需要访问第 k 个」的问题，塞进一次线性扫描里顺便做完。三种原语覆盖绝大多数题：反转（把顺序倒过来）、合并（把两条有序序列拼成一条）、切半（把一条拆成两条）。而两个指针的「定距」是定位问题的通用解法：fast 先走 n 步，两者同步前进，fast 走到末尾时 slow 恰好停在目标位置。

以反转为例，指针翻转每一步要同时知道三件事：当前节点 cur、它的后继（不改就找不到下一站）、以及已翻好的前缀尾巴 prev，于是有了「暂存后继 → 翻转指向 → 两个指针前移」这个三步一循环的模板。虚拟头节点是另一个反复出现的机制：它是一个值为 0 的普通节点，挂在原 head 前面，于是「头节点」不再是特例——删第一个节点和删第 k 个节点共用同一段代码，返回时交出 dummy.next。

text
翻转前:  1 -> 2 -> 3 -> 4 -> nil
一轮三动作: next = cur.next → cur.next = prev → prev, cur = cur, next
翻转后:  4 -> 3 -> 2 -> 1 -> nil

3. 套路清单 ​

套路做法复杂度备注
虚拟头节点dummy := &Node{}，让 dummy.next 指向原 head，所有操作从 dummy 起手时间不变，空间 O(1)删除/插入头节点不再需要特判；返回的是 dummy.next
三指针翻转暂存 next = cur.next → cur.next = prev → prev、cur 一起前移时间 O(n)，空间 O(1)暂存 next 必须写在改 next 之前，否则后缀整段丢失
归并接链dummy + tail，每轮比较两条链头，把较小者接到 tail 后并推进 tail时间 O(n+m)，空间 O(1)用 <= 保证稳定；一条链空掉后把另一条剩余整段接上，不必逐个拷贝
定距快慢指针fast 先走 n 步，再与 slow 同步走，直到 fast.next 为空时间 O(L)，空间 O(1)终止条件是 fast.next == nil 而非 fast == nil，差一步就删错节点
切半 + 反转 + 编织slow/fast 找中点 → 反转后半段 → 两段交替接龙时间 O(n)，空间 O(1)切完必须 slow.next = nil 断开，否则编织会成环

4. Go 实现 ​

四道题共用同一个节点定义 Node（字段名刻意与仓库的 ListNode 不同，避免混淆）。4.1–4.4 给的是片段实现，4.5 是可直接 go run 的完整程序。

4.1 0206 Reverse Linked List（Easy） ​

题目要点：给定链表头节点，把整条链表原地反转并返回新头；节点数 0–5000，允许空链表。

教学实现

go
// reverseList 三指针原地翻转：暂存 next → 翻转 cur.next → 前移。
func reverseList(head *Node) *Node {
	var prev *Node
	for cur := head; cur != nil; {
		next := cur.next
		cur.next = prev
		prev = cur
		cur = next
	}
	return prev
}

讲解

  • prev 一开始是 nil，它同时兼任「已翻好的前缀的尾巴」和「原链表的 nil 尾巴」，所以不需要额外哨兵节点；next := cur.next 必须写在 cur.next = prev 之前，改完指针原后继就再也拿不到，顺序写反后面整段链直接消失。
  • 循环结束时 cur 是 nil，此时 prev 是原链表最后一个节点，也就是新链表的头，所以返回 prev 而不是 head；空链表根本不进循环，返回 nil。

运行结果

text
=== 0206 Reverse Linked List ===
[1,2,3,4,5] -> [5,4,3,2,1]
[] -> []
[1,1,2] -> [2,1,1]

仓库实现：0206-reverse-linked-list/solution.go（含基准测试与性能数据，可回查完整工程化写法）

4.2 0021 Merge Two Sorted Lists（Easy） ​

题目要点：把两条非递减有序链表合成一条有序链表，必须复用原节点（splicing）而不是新建节点；单条最长 50 个节点，允许为空。

教学实现

go
// mergeTwoLists dummy + tail 归并接链：重链接输入节点，零新分配。
func mergeTwoLists(a, b *Node) *Node {
	dummy := &Node{}
	tail := dummy
	for a != nil && b != nil {
		if a.val <= b.val {
			tail.next = a
			a = a.next
		} else {
			tail.next = b
			b = b.next
		}
		tail = tail.next
	}
	if a != nil {
		tail.next = a
	} else {
		tail.next = b
	}
	return dummy.next
}

讲解

  • dummy 消掉了「第一次往结果里接哪个节点」的分支：dummy.next 恒为结果链的头，tail 恒为结果链的尾；比较用 <= 而不是 <，相等时优先取 a，结果稳定，跟标准库的 merge 行为一致。
  • 三个赋值有严格顺序：先挂到 tail.next，再推进源指针，最后推进 tail，少任何一个都会丢节点或成环；循环退出时必有一条链已空，剩下的整段接上即可，这一步是 O(1)，全程零新分配。

运行结果

text
=== 0021 Merge Two Sorted Lists ===
[1,2,4] + [1,3,4] -> [1,1,2,3,4,4]
[] + [] -> []
[1,1] + [1,1] -> [1,1,1,1]

仓库实现：0021-merge-two-sorted-lists/solution.go

4.3 0019 Remove Nth Node From End of List（Medium） ​

题目要点：删掉链表的倒数第 n 个节点并返回新头；1 <= n <= sz，n 可以等于链表长度（删的就是头节点）；follow-up 明确要求一趟完成。

教学实现

go
// removeNthFromEnd dummy + 定距快慢指针，一趟删掉倒数第 n 个节点。
func removeNthFromEnd(head *Node, n int) *Node {
	dummy := &Node{next: head}
	fast := dummy
	for i := 0; i < n; i++ {
		fast = fast.next
	}
	slow := dummy
	for fast.next != nil {
		slow = slow.next
		fast = fast.next
	}
	slow.next = slow.next.next
	return dummy.next
}

讲解

  • fast 从 dummy 出发先走 n 步，于是 slow 与 fast 恒定差 n 个节点，同步前进时 slow 永远停在待删节点的前一个；终止条件是 fast.next != nil 而不是 fast != nil，写错会让 slow 多前移一位，删掉倒数第 n+1 个。
  • dummy 让「删的就是原 head」不需要特判，此时 slow 停在 dummy 上、slow.next 就是原 head，n 等于链表长度时同步循环一次都不进；删除只改一行 slow.next = slow.next.next，右边先求值再赋值，写反会解引用空指针。

运行结果

text
=== 0019 Remove Nth Node From End of List ===
[1,2,3,4,5] n=2 -> [1,2,3,5]
[1] n=1 -> []
[1,2] n=2 -> [2]

仓库实现：0019-remove-nth-node-from-end-of-list/solution.go

4.4 0143 Reorder List（Medium） ​

题目要点：把 L0 → L1 → … → Ln 原地重排成 L0 → Ln → L1 → Ln-1 → …；只许改指针不许改值；节点数 1–5×10^4。

教学实现

go
// reorderList 找中点 → 反转后半段 → 交替编织。反转复用 4.1 的 reverseList。
func reorderList(head *Node) {
	if head == nil || head.next == nil {
		return
	}
	// 1. 找中点：slow 停在第一半的末尾
	slow, fast := head, head
	for fast.next != nil && fast.next.next != nil {
		slow = slow.next
		fast = fast.next.next
	}
	// 2. 断开前半段，反转后半段
	second := reverseList(slow.next)
	slow.next = nil
	// 3. 交替编织
	first := head
	for second != nil {
		firstNext, secondNext := first.next, second.next
		first.next = second
		second.next = firstNext
		first = firstNext
		second = secondNext
	}
}

讲解

  • fast 走两步、slow 走一步，条件 fast.next != nil && fast.next.next != nil 保证 slow 落在第一半的最后一个节点上（5 个节点时停在第 3 个，4 个节点时停在第 2 个）；slow.next = nil 不能省，不断开的话前半段的尾巴还指着后半段的头，编织时必然成环。
  • 编织时先把两个「下一步」（firstNext、secondNext）存下来再改 next，指针一改原后继就再也取不回来；循环以 second 为终止条件，后半段先耗尽时前半段剩下的节点保持原有顺序自然收尾。

运行结果

text
=== 0143 Reorder List ===
[1,2,3,4] -> [1,4,2,3]
[1,2,3,4,5] -> [1,5,2,4,3]
[1] -> [1]

仓库实现：0143-reorder-list/solution.go

4.5 完整可运行示例 ​

下面这份程序可直接 go run（只用标准库）。它包含 4.1–4.4 的全部教学实现——代码与上面逐字一致（含注释）——以及覆盖全部用例的 main。

go
package main

import "fmt"

// Node 是本篇教学版自用的链表节点，字段名与仓库的 ListNode 刻意不同。
type Node struct {
	val  int
	next *Node
}

// reverseList 三指针原地翻转：暂存 next → 翻转 cur.next → 前移。
func reverseList(head *Node) *Node {
	var prev *Node
	for cur := head; cur != nil; {
		next := cur.next
		cur.next = prev
		prev = cur
		cur = next
	}
	return prev
}

// mergeTwoLists dummy + tail 归并接链：重链接输入节点，零新分配。
func mergeTwoLists(a, b *Node) *Node {
	dummy := &Node{}
	tail := dummy
	for a != nil && b != nil {
		if a.val <= b.val {
			tail.next = a
			a = a.next
		} else {
			tail.next = b
			b = b.next
		}
		tail = tail.next
	}
	if a != nil {
		tail.next = a
	} else {
		tail.next = b
	}
	return dummy.next
}

// removeNthFromEnd dummy + 定距快慢指针，一趟删掉倒数第 n 个节点。
func removeNthFromEnd(head *Node, n int) *Node {
	dummy := &Node{next: head}
	fast := dummy
	for i := 0; i < n; i++ {
		fast = fast.next
	}
	slow := dummy
	for fast.next != nil {
		slow = slow.next
		fast = fast.next
	}
	slow.next = slow.next.next
	return dummy.next
}

// reorderList 找中点 → 反转后半段 → 交替编织。反转复用 4.1 的 reverseList。
func reorderList(head *Node) {
	if head == nil || head.next == nil {
		return
	}
	// 1. 找中点：slow 停在第一半的末尾
	slow, fast := head, head
	for fast.next != nil && fast.next.next != nil {
		slow = slow.next
		fast = fast.next.next
	}
	// 2. 断开前半段，反转后半段
	second := reverseList(slow.next)
	slow.next = nil
	// 3. 交替编织
	first := head
	for second != nil {
		firstNext, secondNext := first.next, second.next
		first.next = second
		second.next = firstNext
		first = firstNext
		second = secondNext
	}
}

// build 从切片建链表。
func build(vals []int) *Node {
	dummy := &Node{}
	tail := dummy
	for _, v := range vals {
		tail.next = &Node{val: v}
		tail = tail.next
	}
	return dummy.next
}

// showList 把链表渲染成 [1,2,3] 的形式。
func showList(head *Node) string {
	s := "["
	for cur := head; cur != nil; cur = cur.next {
		if s != "[" {
			s += ","
		}
		s += fmt.Sprint(cur.val)
	}
	return s + "]"
}

func main() {
	fmt.Println("=== 0206 Reverse Linked List ===")
	fmt.Printf("[1,2,3,4,5] -> %s\n", showList(reverseList(build([]int{1, 2, 3, 4, 5}))))
	fmt.Printf("[] -> %s\n", showList(reverseList(build(nil))))
	fmt.Printf("[1,1,2] -> %s\n", showList(reverseList(build([]int{1, 1, 2}))))

	fmt.Println("=== 0021 Merge Two Sorted Lists ===")
	fmt.Printf("[1,2,4] + [1,3,4] -> %s\n", showList(mergeTwoLists(build([]int{1, 2, 4}), build([]int{1, 3, 4}))))
	fmt.Printf("[] + [] -> %s\n", showList(mergeTwoLists(build(nil), build(nil))))
	fmt.Printf("[1,1] + [1,1] -> %s\n", showList(mergeTwoLists(build([]int{1, 1}), build([]int{1, 1}))))

	fmt.Println("=== 0019 Remove Nth Node From End of List ===")
	fmt.Printf("[1,2,3,4,5] n=2 -> %s\n", showList(removeNthFromEnd(build([]int{1, 2, 3, 4, 5}), 2)))
	fmt.Printf("[1] n=1 -> %s\n", showList(removeNthFromEnd(build([]int{1}), 1)))
	fmt.Printf("[1,2] n=2 -> %s\n", showList(removeNthFromEnd(build([]int{1, 2}), 2)))

	fmt.Println("=== 0143 Reorder List ===")
	for _, vals := range [][]int{{1, 2, 3, 4}, {1, 2, 3, 4, 5}, {1}} {
		h := build(vals)
		label := showList(h)
		reorderList(h)
		fmt.Printf("%s -> %s\n", label, showList(h))
	}
}

5. 变体与边界 ​

  1. 区间反转（0092 Reverse Linked List II）：只反转 [m, n] 这一段。要多改的是「prev 从哪开始」——先走到第 m-1 个节点当 prev，再套 0206 的模板，翻完把 prev.next 指向新的段头。
  2. 旋转链表（0061 Rotate List）：把链表切成两段再交换位置。要多改的是「切分点」——用长度取模算出切点，断开后接上，全程不涉及反转。
  3. 合并 k 条有序链表（0023 Merge k Sorted Lists）：两路归并升级成多路。要多改的是「下一个节点怎么选」——用最小堆维护 k 个链头，每次弹最小并推进对应链。
  4. 环形链表判定（0141 Linked List Cycle）：同样用快慢指针，但要改推进步数——slow 走一步、fast 走两步，相遇即有环；找入环点则在相遇后 slow 走一步、fast 走两步。
  5. 不要求原地时的兜底：把节点全存进 slice，用下标做头尾交替（0143 的栈解法即如此）。要多改的是「放弃 O(1) 空间」，换来十来行就能写完。

6. 常见错误 ​

  1. 改 next 之前没暂存 next → 后缀整段丢失，链表从此断开。改法：先 next := cur.next，再写 cur.next = ...。
  2. 删除头节点单开一条分支 → 两套代码两份 bug。改法：上 dummy，让 slow 永远停在待删节点的前一个位置。
  3. 定距指针终止条件写成 fast != nil → slow 多前移一位，删掉倒数第 n+1 个。改法：条件是 fast.next != nil。
  4. 合并时用 < 而不是 <= → 相等元素时不稳定，与 std::merge 行为不一致。改法：统一用 <=。
  5. 切半后忘了 slow.next = nil → 前后两半还连着，编织时首尾相接成环。改法：反转后立刻断开。
