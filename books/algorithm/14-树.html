14 树 ​

树题只做三件事：定节点含义、定返回值、定左右次序。 适合：BST 判定、最近公共祖先、路径最大和、序列化。

1. 场景 ​

输入是一棵二叉树（题面给层序数组），输出往往只有一个数或一个布尔值。约束里没有可利用的值域，只有节点数上限，所以目标只能是 O(n)。

决定性条件藏在结构契约里，不在数值范围里。0098 的题面说「BST」，那么「左小右大」是整棵子树的性质，不是父子两点的比较；0236 给的是普通树，什么性质都没有，信息只能靠遍历汇总；0124 的「路径」允许拐弯，答案不一定经过根；0297 要求「还原成同一棵树」，那就必须连空孩子一起编码。

认出这类题的信号：给一棵树，问「满不满足某个全局性质」「两个节点的最近公共祖先」「最大路径和」「能不能存成字符串再读回来」。

2. 核心机制 ​

树是递归结构：每个节点的答案都能由两个子树的答案合成。所以树题真正要定的只有三件事——节点表示什么、递归函数返回什么、左右孩子的次序怎么排。

返回值向上汇总，副作用向下传递。 大多数树题需要两条通道：函数返回值把子树信息交给父节点，外部变量把「到目前为止最好的答案」记下来。0124 是典型：函数返回「以我为端点向下走的最优和」，答案本身却记在 best 里——因为「经过当前节点的最优路径」可能同时用上左右两个孩子，这种路径没法用一个返回值表达。

BST 的性质是全局的，验证必须带上下界。 只比父子会漏判：[10,5,15,null,null,6,20] 里 15 的左孩子 6 同时在 10 的右子树里，父子比较全部通过，但 BST 要求 10 的整棵右子树都大于 10，而 6 < 10 直接违规。正确做法是把祖先给的上下界一路传下去。

普通树没有可用的性质，LCA 只能靠「子树里有没有目标」汇总。 0236 的递归函数返回「这棵子树里捞到的目标节点」：左右都捞到了，说明目标分居两侧，当前节点就是 LCA；只有一边捞到，就把它往上带。

序列化必须让「空位置」可编码。 只写前序，值相同的不同形状会编成同一个串。补上 null 标记后，每个空孩子都占一个 token，前序加 null 就是唯一编码；还原时按同样的顺序取 token，遇到 null 就造空节点。

3. 套路清单 ​

套路做法复杂度备注
BST 验证带界递归：把祖先给的 (lo, hi) 传给左右孩子；或迭代中序，跟踪上一个值时间 O(n)，栈 O(h)只比父子会漏判；严格递增才算 BST
BST 上的 LCA从根按 p、q 的大小关系单路下走时间 O(h)，空间 O(1)依赖「左小右大」，普通树不适用
普通树 LCA后序遍历，左右子树都返回非空即分居两侧时间 O(n)，栈 O(h)命中目标就返回，节点是自身的祖先
树上路径 DP左右高度向上传，V 形路径用外部变量记答案时间 O(n)，栈 O(h)返回值只能带一条分支，负贡献截断为 0
序列化 / 反序列化前序加 null 占位，串接 token时间 O(n)，空间 O(n)少写 null 就分不清不同形状

4. Go 实现 ​

五道题共用一条主线：想清楚递归函数该返回什么，再把「返回值」和「副作用」分开放。4.1–4.5 给的是片段，4.6 是可直接 go run 的完整程序。

4.1 0098 Validate Binary Search Tree（Medium） ​

题目要点：给一棵二叉树，判断它是不是合法 BST——每个节点的左子树里所有值都严格小于它，右子树里所有值都严格大于它。

教学实现

go
// IsValidBST 判断 root 是不是合法 BST：每个节点都得落在祖先给的 (lo, hi) 开区间里。
func IsValidBST(root *TreeNode) bool {
	return validBST(root, math.MinInt, math.MaxInt)
}

// validBST 把开区间 (lo, hi) 一路往下传。
func validBST(n *TreeNode, lo, hi int) bool {
	if n == nil {
		return true
	}
	if n.Val <= lo || n.Val >= hi {
		return false
	}
	return validBST(n.Left, lo, n.Val) && validBST(n.Right, n.Val, hi)
}

讲解：关键是 validBST 的两个参数 (lo, hi)：它们不是父子节点的值，而是祖先链给出的合法区间。往左走时上界收紧成当前值，往右走时下界抬高成当前值，于是每个节点都被夹在「所有祖先的最严格约束」之间。只比父子的话，[10,5,15,null,null,6,20] 这种「局部父子都合法、整体却违规」的树会被放过。开区间用 <= / >= 判掉相等，符合 BST 严格递增的定义；根那一层传 math.MinInt / math.MaxInt 表示无约束，题目值域是 int32，不会撞边界。空树返回 true——没有任何节点违反任何约束。

运行结果

text
0098 [2 1 3] -> valid=true
0098 [10 5 15 null null 6 20] -> valid=false
0098 empty -> valid=true

4.2 0235 Lowest Common Ancestor of a Binary Search Tree（Medium） ​

题目要点：给一棵 BST 和两个节点 p、q，返回它们的最近公共祖先（节点可以是自身的祖先）。

教学实现

go
// LowestCommonAncestorBST 靠 BST 的大小关系只走一条路径。
func LowestCommonAncestorBST(root, p, q *TreeNode) *TreeNode {
	for cur := root; cur != nil; {
		switch {
		case p.Val < cur.Val && q.Val < cur.Val:
			cur = cur.Left
		case p.Val > cur.Val && q.Val > cur.Val:
			cur = cur.Right
		default:
			return cur
		}
	}
	return nil
}

讲解：「左小右大」是不变量，于是不必遍历整棵树：从根开始单路下走——p、q 都比当前小就往左，都比当前大就往右，否则当前节点就是 LCA。最后那个「否则」覆盖两种情况：p、q 分居当前节点两侧（当前节点是分叉点），或者 p、q 之一就是当前节点本身。代价是这招只在 BST 上成立，普通树按大小关系选方向毫无依据。平衡树 h = O(log n)，退化成链时 h = O(n)，但空间始终是 O(1)。

运行结果

text
0235 p=2 q=8 -> lca=6
0235 p=3 q=5 -> lca=4
0235 p=0 q=9 -> lca=6

仓库实现：0235-lowest-common-ancestor-of-a-binary-search-tree/solution.go

4.3 0236 Lowest Common Ancestor of a Binary Tree（Medium） ​

题目要点：给一棵普通二叉树和两个节点 p、q，返回它们的最近公共祖先。

教学实现

go
// LowestCommonAncestorBT 后序遍历：返回子树里捞到的那个目标节点。
func LowestCommonAncestorBT(root, p, q *TreeNode) *TreeNode {
	if root == nil || root == p || root == q {
		return root
	}
	left := LowestCommonAncestorBT(root.Left, p, q)
	right := LowestCommonAncestorBT(root.Right, p, q)
	if left != nil && right != nil {
		return root
	}
	if left != nil {
		return left
	}
	return right
}

讲解：普通树没有大小关系可用，只能靠后序遍历把「子树里有没有目标」汇总上来。返回值的语义是「这棵子树里能捞到的那个目标节点」：左右都捞到了，说明 p、q 分居两侧，当前节点就是 LCA；只有一边捞到，说明两个目标都在那边，把那一个继续往上带。注意 root == p || root == q 必须立刻返回——题目允许「节点是自身的祖先」，此时它自己就是 LCA，再往下递归会错过答案。这正是 0235 与 0236 的分工：一个用大小关系选方向，一个用「左右返回非空」判定分叉。

运行结果

text
0236 p=5 q=1 -> lca=3
0236 p=5 q=4 -> lca=5
0236 p=7 q=4 -> lca=2

仓库实现：0236-lowest-common-ancestor-of-a-binary-tree/solution.go

4.4 0124 Binary Tree Maximum Path Sum（Hard） ​

题目要点：给一棵二叉树，返回任意非空路径的最大点权和；路径可以拐弯，不一定经过根。

教学实现

go
// MaxPathSum 返回任意非空路径的最大和：左右高度向上传，全局量记答案。
func MaxPathSum(root *TreeNode) int {
	best := math.MinInt
	var gain func(n *TreeNode) int
	gain = func(n *TreeNode) int {
		if n == nil {
			return 0
		}
		left, right := max(gain(n.Left), 0), max(gain(n.Right), 0)
		best = max(best, n.Val+left+right)
		return n.Val + max(left, right)
	}
	gain(root)
	return best
}

讲解：同一个递归干了两件事，所以有「双口径」：gain 返回「以当前节点为端点、向下走一条分支能拿到的最大和」，外部变量 best 记「经过当前节点的最优路径」。经过当前节点的路径可以同时接上左右两支，和是 n.Val + left + right，这个值没法用返回值表达（父节点只接一条分支），只能记在外部。返回值那一步必须截断成单分支 n.Val + max(left, right)，两条都传上去父节点就不知道该怎么接。两个边界：负贡献要截断到 0（max(gain(n.Left), 0)，路径不值得绕进去就断开）；best 初值必须是 math.MinInt 而不是 0，否则全负的树会返回 0，而题面要的是非空路径的最大和（[-3] 应得 -3）。

运行结果

text
0124 [1 2 3] -> max=6
0124 [-10 9 20 null null 15 7] -> max=42
0124 [-3] -> max=-3

仓库实现：0124-binary-tree-maximum-path-sum/solution.go

4.5 0297 Serialize and Deserialize Binary Tree（Hard） ​

题目要点：把二叉树编码成一个字符串，并能把字符串还原成同一棵树；不限制编码格式。

教学实现

go
// Serialize 用前序 + "null" 占位把树拍成 token 串。
func Serialize(root *TreeNode) string {
	var sb strings.Builder
	var walk func(n *TreeNode)
	walk = func(n *TreeNode) {
		if n == nil {
			sb.WriteString("null ")
			return
		}
		sb.WriteString(strconv.Itoa(n.Val) + " ")
		walk(n.Left)
		walk(n.Right)
	}
	walk(root)
	return strings.TrimRight(sb.String(), " ")
}

// Deserialize 按前序逐 token 读回树："null" 就是一个空节点。
func Deserialize(data string) *TreeNode {
	tokens, idx := strings.Fields(data), 0
	var build func() *TreeNode
	build = func() *TreeNode {
		if idx >= len(tokens) || tokens[idx] == "null" {
			idx++
			return nil
		}
		v, _ := strconv.Atoi(tokens[idx])
		idx++
		n := &TreeNode{Val: v}
		n.Left = build()
		n.Right = build()
		return n
	}
	return build()
}

讲解：格式自由，但必须无损。只写前序遍历会丢信息：[1,2] 和 [2,1] 的前序都是 1 2，形状却不同，所以必须连空位置一起编码——这里用 null 标记每个空孩子，于是「根 | 左子树 | 右子树」里每个空孩子也占一位，前序加 null 就是唯一编码。还原时按同样顺序取 token：遇到 null 返回空节点，遇到数字就建节点，然后按前序顺序递归取左子树、再取右子树。两个坑：每个 token 都要消耗一次下标（null 也消耗），漏掉就整体错位；空树也要输出一个 null，否则反序列化端无法区分「空串」和「一个 null」。strings.Fields 会自动吃掉多余空白，比 strings.Split 宽容。

运行结果

text
0297 [1 2 3 null null 4 5] -> "1 2 null null 3 4 null null 5 null null"
0297 empty -> "null"
0297 [-1 -2 -3] -> "-1 -2 null null -3 null null"

仓库实现：0297-serialize-and-deserialize-binary-tree/solution.go

4.6 完整可运行示例 ​

下面这份程序可以直接 go run（只用标准库）。它包含 4.1–4.5 的全部教学实现——代码与上面逐字一致（含注释）——以及覆盖全部用例的 main。

go
package main

import (
	"fmt"
	"math"
	"strconv"
	"strings"
)

// TreeNode 是二叉树节点。
type TreeNode struct {
	Val   int
	Left  *TreeNode
	Right *TreeNode
}

// IsValidBST 判断 root 是不是合法 BST：每个节点都得落在祖先给的 (lo, hi) 开区间里。
func IsValidBST(root *TreeNode) bool {
	return validBST(root, math.MinInt, math.MaxInt)
}

// validBST 把开区间 (lo, hi) 一路往下传。
func validBST(n *TreeNode, lo, hi int) bool {
	if n == nil {
		return true
	}
	if n.Val <= lo || n.Val >= hi {
		return false
	}
	return validBST(n.Left, lo, n.Val) && validBST(n.Right, n.Val, hi)
}

// LowestCommonAncestorBST 靠 BST 的大小关系只走一条路径。
func LowestCommonAncestorBST(root, p, q *TreeNode) *TreeNode {
	for cur := root; cur != nil; {
		switch {
		case p.Val < cur.Val && q.Val < cur.Val:
			cur = cur.Left
		case p.Val > cur.Val && q.Val > cur.Val:
			cur = cur.Right
		default:
			return cur
		}
	}
	return nil
}

// LowestCommonAncestorBT 后序遍历：返回子树里捞到的那个目标节点。
func LowestCommonAncestorBT(root, p, q *TreeNode) *TreeNode {
	if root == nil || root == p || root == q {
		return root
	}
	left := LowestCommonAncestorBT(root.Left, p, q)
	right := LowestCommonAncestorBT(root.Right, p, q)
	if left != nil && right != nil {
		return root
	}
	if left != nil {
		return left
	}
	return right
}

// MaxPathSum 返回任意非空路径的最大和：左右高度向上传，全局量记答案。
func MaxPathSum(root *TreeNode) int {
	best := math.MinInt
	var gain func(n *TreeNode) int
	gain = func(n *TreeNode) int {
		if n == nil {
			return 0
		}
		left, right := max(gain(n.Left), 0), max(gain(n.Right), 0)
		best = max(best, n.Val+left+right)
		return n.Val + max(left, right)
	}
	gain(root)
	return best
}

// Serialize 用前序 + "null" 占位把树拍成 token 串。
func Serialize(root *TreeNode) string {
	var sb strings.Builder
	var walk func(n *TreeNode)
	walk = func(n *TreeNode) {
		if n == nil {
			sb.WriteString("null ")
			return
		}
		sb.WriteString(strconv.Itoa(n.Val) + " ")
		walk(n.Left)
		walk(n.Right)
	}
	walk(root)
	return strings.TrimRight(sb.String(), " ")
}

// Deserialize 按前序逐 token 读回树："null" 就是一个空节点。
func Deserialize(data string) *TreeNode {
	tokens, idx := strings.Fields(data), 0
	var build func() *TreeNode
	build = func() *TreeNode {
		if idx >= len(tokens) || tokens[idx] == "null" {
			idx++
			return nil
		}
		v, _ := strconv.Atoi(tokens[idx])
		idx++
		n := &TreeNode{Val: v}
		n.Left = build()
		n.Right = build()
		return n
	}
	return build()
}

// n 造一个节点，nil 表示空孩子。
func n(v int, l, r *TreeNode) *TreeNode {
	return &TreeNode{Val: v, Left: l, Right: r}
}

func main() {
	fmt.Printf("0098 [2 1 3] -> valid=%v\n", IsValidBST(n(2, n(1, nil, nil), n(3, nil, nil))))
	fmt.Printf("0098 [10 5 15 null null 6 20] -> valid=%v\n", IsValidBST(n(10, n(5, nil, nil), n(15, n(6, nil, nil), n(20, nil, nil)))))
	fmt.Printf("0098 empty -> valid=%v\n", IsValidBST(nil))
	t2, t8 := n(2, n(0, nil, nil), n(4, n(3, nil, nil), n(5, nil, nil))), n(8, n(7, nil, nil), n(9, nil, nil))
	bst := n(6, t2, t8)
	fmt.Printf("0235 p=2 q=8 -> lca=%d\n", LowestCommonAncestorBST(bst, t2, t8).Val)
	fmt.Printf("0235 p=3 q=5 -> lca=%d\n", LowestCommonAncestorBST(bst, t2.Right.Left, t2.Right.Right).Val)
	fmt.Printf("0235 p=0 q=9 -> lca=%d\n", LowestCommonAncestorBST(bst, t2.Left, t8.Right).Val)
	u5, u1 := n(5, n(6, nil, nil), n(2, n(7, nil, nil), n(4, nil, nil))), n(1, n(0, nil, nil), n(8, nil, nil))
	bt := n(3, u5, u1)
	fmt.Printf("0236 p=5 q=1 -> lca=%d\n", LowestCommonAncestorBT(bt, u5, u1).Val)
	fmt.Printf("0236 p=5 q=4 -> lca=%d\n", LowestCommonAncestorBT(bt, u5, u5.Right.Right).Val)
	fmt.Printf("0236 p=7 q=4 -> lca=%d\n", LowestCommonAncestorBT(bt, u5.Right.Left, u5.Right.Right).Val)
	fmt.Printf("0124 [1 2 3] -> max=%d\n", MaxPathSum(n(1, n(2, nil, nil), n(3, nil, nil))))
	fmt.Printf("0124 [-10 9 20 null null 15 7] -> max=%d\n", MaxPathSum(n(-10, n(9, nil, nil), n(20, nil, n(15, nil, n(7, nil, nil))))))
	fmt.Printf("0124 [-3] -> max=%d\n", MaxPathSum(n(-3, nil, nil)))
	fmt.Printf("0297 [1 2 3 null null 4 5] -> %q\n", Serialize(n(1, n(2, nil, nil), n(3, n(4, nil, nil), n(5, nil, nil)))))
	fmt.Printf("0297 empty -> %q\n", Serialize(nil))
	fmt.Printf("0297 [-1 -2 -3] -> %q\n", Serialize(n(-1, n(-2, nil, nil), n(-3, nil, nil))))
}

5. 变体与边界 ​

  1. BST 验证换中序：把 (lo, hi) 换成「跟踪上一个中序值」，同样 O(n) 但不传区间参数；0230 Kth Smallest Element in a BST（Medium）、0099 Recover Binary Search Tree（Medium） 都是这个套路。
  2. 单路下走的推广：0700 Search in a Binary Search Tree（Easy） 与 0235 同源，靠大小关系定位目标；BST 上还能用「p、q 值域夹逼」直接判分叉，迭代版空间 O(1)。
  3. 普通树 LCA 换父指针法：先 BFS 建 parent map，再让 p 一路上行打标记、q 一路上行找第一个命中的节点——0236-lowest-common-ancestor-of-a-binary-tree/other-best-answers/lee215-parent-map.md 是这个版本，代价是 O(n) 额外内存但不吃递归栈。
  4. 路径 DP 换口径：0124 的「双口径」照搬到 0543 Diameter of Binary Tree（Easy）（直径 = 左右深度之和）和 0687 Longest Univalue Path（Medium），只需换掉 best 的更新公式，骨架不动。
  5. 序列化换层序：0297 也可以用队列做层序编码，每个空孩子输出 null，串更长但树接近完全二叉树时更直观——0297-serialize-and-deserialize-binary-tree/other-best-answers/bfs-level-order.md 是这个版本；0331 Verify Preorder Serialization of a Binary Tree（Medium） 则是同一件事的「只验证不还原」变体。

6. 常见错误 ​

  1. 0098 只比父子、还漏了严格性：写成 left.Val < n.Val && n.Val < right.Val 就收工，[10,5,15,null,null,6,20] 这种树会被误判成合法；边界还得用 <= / >= 判掉相等。
  2. 0235 的招套到普通树：0236 上按大小关系选方向毫无依据，普通树只能用「左右返回非空」；反过来把 0236 的整树后序套到 BST 上也对，只是白费了排序性质。
  3. 0236 命中目标还继续递归：root == p || root == q 时必须立刻返回，否则「节点是自身祖先」的情况会判错。
  4. 0124 返回值带了双分支：把 n.Val + left + right 当返回值传给父节点，父节点再一接就拼出分叉路径，答案会虚高；返回值只能是 n.Val + max(left, right)。
  5. 0124 的 best 初值写成 0：全负的树（[-3]）会返回 0，而题面要的是非空路径；初值必须是 math.MinInt。
