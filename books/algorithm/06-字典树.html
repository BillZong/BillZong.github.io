06 字典树 ​

把公共前缀合并成一棵树，前缀查询就退化成沿边走。 适合：前缀匹配、通配符查找、网格里找单词。

1. 场景 ​

输入是一堆字符串，输出却是「有没有」「有哪几个」这类存在性问题：不要求顺序，不要求位置，只要「在不在」。

约束里藏着两个决定性条件：字符集只有 26 个小写字母（于是节点的孩子能定长开成一维数组），查询以字符串前缀的形式出现（于是「查一个词」和「查一堆词」是同一件事）。识别信号：按前缀过滤、自动补全、网格里找出所有能拼出来的词、查询里带通配符。

2. 核心机制 ​

字典树把「公共前缀」这层结构显式存进内存：所有以同一串开头的词共用同一条路径。于是「有没有以 p 开头的词」不必遍历词库，而是一次沿边下降——走得到就是有，走不到就是没有。代价是空间换时间：节点数约等于所有词的总字符数减去重复前缀，查询是 O(L)（L 为串长），与词库大小无关。

节点上挂什么，决定它能回答哪类问题。挂「此处是完整单词」的标记，就能区分「这个词在库里」和「这个前缀在库里」——0208 的 search 与 startsWith 是同一枚标记的两种读法。挂一个整词，就顺手拿到了 0212 需要的输出：命中某个节点时，节点上存的整词就是要报出的答案。挂一个计数，则得到了「以 p 开头的词有多少个」。

3. 套路清单 ​

套路做法复杂度备注
建树沿字符逐层下行，缺孩子就建一个，到末尾记下整词插入 O(L)字符集固定 26 时定长数组比 map 快
精确查找沿路径走到底，要求末节点带词标记O(L)只判「路径存在」会把前缀误判成词
前缀匹配沿路径走到底，不看标记O(L)空前缀恒为真（根节点总可达）
通配符匹配遇 . 枚举 26 个分支，其余照常下行O(26^k · L). 只匹配一个字符，不是正则
网格找词词建 trie，网格上 DFS 时沿 trie 走最坏 O(m·n·4^L)路径不在 trie 里立刻剪枝
命中即剪枝命中后清空标记；末节点无孩子就断开这条边同上同一词只报一次，死分支不再走

4. Go 实现 ​

下面是教学版实现，比仓库版短：不做容量预分配、不做防御性包装，只保留教学点。三者与仓库实现做过差分对拍（固定边界用例 + 固定种子随机用例 + 暴力解 oracle），结果完全一致。

4.1 0208 Implement Trie (Prefix Tree)（Medium） ​

题目要点：实现前缀树，支持插入单词、精确查找单词、判断是否有单词以某串开头；串长上限 2000，只含小写字母。

教学实现

go
// Trie 是前缀树：每个节点 26 个孩子槽，word 记「在这里结束的完整单词」。
type Trie struct {
	children [26]*Trie
	word     string
}

// Insert 沿字符逐层下行，缺哪层补哪层；走到末尾记下整个单词。
func (t *Trie) Insert(word string) {
	cur := t
	for i := 0; i < len(word); i++ {
		c := word[i] - 'a'
		if cur.children[c] == nil {
			cur.children[c] = &Trie{}
		}
		cur = cur.children[c]
	}
	cur.word = word
}

// find 沿 s 逐字符下行，返回走到的节点；中途断了返回 nil。
func (t *Trie) find(s string) *Trie {
	cur := t
	for i := 0; i < len(s); i++ {
		cur = cur.children[s[i]-'a']
		if cur == nil {
			return nil
		}
	}
	return cur
}

// Search 要求走到末尾，且末尾节点确实是一个完整单词。
func (t *Trie) Search(word string) bool {
	n := t.find(word)
	return n != nil && n.word != ""
}

func (t *Trie) StartsWith(prefix string) bool {
	return t.find(prefix) != nil
}

讲解

  • word 存的是「在这个节点结束的完整单词」，不是布尔标记。一个字段既能回答「是不是词」（search），又能直接给出答案本身（0212 的 findWords），标记与输出共用一处。
  • 查得到节点不等于查得到词：库里只有 apple 时，app 只是路径上的一段，app 节点的 word 是空的，所以 search("app") 必须是 false。
  • find 里 cur = cur.children[...] 之后立刻判 nil；一旦 cur 变成 nil 就不能再下标，否则 panic。StartsWith 只看路径通不通，因此比 Search 松：库里有 apple，startsWith("app") 就是 true。
  • 空串是边界：空串走到根节点，所以 Search("") 为 false（根上没词），StartsWith("") 却为 true（根总可达）。题面约束串长 ≥ 1，判题碰不到，自己写测试会碰到。

运行结果

text
=== 0208 Implement Trie (Prefix Tree) (Medium) ===
    search      "apple"  = true
    search      "app"    = false
    startsWith  "app"    = true
    search      "app"    = true
    search      "ap"     = false

仓库实现：0208-implement-trie-prefix-tree/solution.go（含基准测试与性能数据，可回查完整工程化写法）

4.2 0211 Design Add and Search Words Data Structure（Medium） ​

题目要点：在字典树之上支持通配符查询，. 代表任意一个小写字母（只代表一个，不是正则）；串长上限 25。

教学实现

下面是查询这一侧的实现（WordDictionary 这个壳与 AddWord 见 4.4）。

go
// Search 匹配 word：'.' 可以代表任意一个小写字母。
func (d *WordDictionary) Search(word string) bool {
	return d.match(&d.root, word, 0)
}

// match 从 node 出发递归匹配 word[i:]；遇到 '.' 就把 26 个分支都试一遍。
func (d *WordDictionary) match(node *Trie, word string, i int) bool {
	if i == len(word) {
		return node.word != ""
	}
	if word[i] == '.' {
		for k := 0; k < 26; k++ {
			if node.children[k] != nil && d.match(node.children[k], word, i+1) {
				return true
			}
		}
		return false
	}
	next := node.children[word[i]-'a']
	return next != nil && d.match(next, word, i+1)
}

讲解

  • 树本身跟 0208 完全一样，WordDictionary 只是个壳：加词走 Trie.Insert，查询另写一套。
  • 遇到 . 必须分叉：把 26 个孩子逐个试过去，只要有一条能走通就立刻返回 true，不必穷举到底。
  • 递归的终止条件是「串走完了」，此时检查当前节点的 word 是否非空——不是「节点存在就赢」，通配符匹配到的路径终点必须真的落在一个词上。
  • . 只匹配一个字符。库里有 bad/dad/mad 时 search("pad") 是 false（pad 没插进去）。复杂度随 . 的个数指数增长：k 个通配符最坏 26^k · L，题目把串长限在 25、调用次数限在 10^4，实测里 . 通常只有三四个。

运行结果

text
=== 0211 Design Add and Search Words Data Structure (Medium) ===
    search      "pad"    = false
    search      ".ad"    = true
    search      "b.."    = true
    search      "..."    = true

仓库实现：0211-design-add-and-search-words-data-structure/solution.go

4.3 0212 Word Search II（Hard） ​

题目要点：在 m×n 网格里找出所有能沿上下左右拼出来的词，同一格在一个词里只能用一次；词库最多 3×10^4 个词、词长最多 10。

教学实现

下面这段是核心的 DFS；完整的 findWords（含建树与外层枚举）见 4.4。

go
	var dfs func(r, c int, node *Trie)
	dfs = func(r, c int, node *Trie) {
		ch := board[r][c]
		child := node.children[ch-'a']
		if child == nil {
			return // 不是任何单词的前缀，剪枝
		}
		if child.word != "" {
			out = append(out, child.word)
			child.word = "" // 同一个单词只报一次
		}
		used[r][c] = true
		for _, d := range dirs {
			nr, nc := r+d[0], c+d[1]
			if nr < 0 || nr >= len(board) || nc < 0 || nc >= len(board[0]) || used[nr][nc] {
				continue
			}
			dfs(nr, nc, child)
		}
		used[r][c] = false
	}

讲解

  • 与 0208 的 Trie 共用一套结构：0212 只是把「查询方」从「一串字符」换成了「网格上的一条路径」。剪枝点是 child == nil：当前路径已经不是任何单词的前缀，后面的分支全是白走，这正是 trie 相对「一个词跑一次 DFS」的价值所在。
  • child.word = "" 做去重：同一个词在网格里往往有多条拼法，清空标记保证只报一次。
  • used[r][c] 标记「本条路径已用」，回溯时必须复位成 false，否则同一格会被重复使用，拼出本不该存在的词（网格只有一格 a 时就不该能拼出 aa）。
  • 边界：网格为空、单格、词库里的词全都比网格长，答案都是空集。

运行结果

text
=== 0212 Word Search II (Hard) ===
  board=oaan/etae/ihkr/iflv words=[oath pea eat rain] -> [eat oath]
  board=a words=[aa] -> []

仓库实现：0212-word-search-ii/solution.go

4.4 完整可运行示例 ​

下面这份程序可直接 go run（只用标准库）。它包含本篇 4.1–4.3 的全部教学实现——代码与上面逐字一致（含注释）——以及覆盖全部用例的 main。运行结果就是上面 4.1–4.3 三个「运行结果」块按顺序拼接，也就是这个程序的完整 stdout。

go
package main

import (
	"fmt"
	"sort"
	"strings"
)

// ===== 0208 Implement Trie (Prefix Tree) =====

// Trie 是前缀树：每个节点 26 个孩子槽，word 记「在这里结束的完整单词」。
type Trie struct {
	children [26]*Trie
	word     string
}

// Insert 沿字符逐层下行，缺哪层补哪层；走到末尾记下整个单词。
func (t *Trie) Insert(word string) {
	cur := t
	for i := 0; i < len(word); i++ {
		c := word[i] - 'a'
		if cur.children[c] == nil {
			cur.children[c] = &Trie{}
		}
		cur = cur.children[c]
	}
	cur.word = word
}

// find 沿 s 逐字符下行，返回走到的节点；中途断了返回 nil。
func (t *Trie) find(s string) *Trie {
	cur := t
	for i := 0; i < len(s); i++ {
		cur = cur.children[s[i]-'a']
		if cur == nil {
			return nil
		}
	}
	return cur
}

// Search 要求走到末尾，且末尾节点确实是一个完整单词。
func (t *Trie) Search(word string) bool {
	n := t.find(word)
	return n != nil && n.word != ""
}

func (t *Trie) StartsWith(prefix string) bool {
	return t.find(prefix) != nil
}

// ===== 0211 Design Add and Search Words Data Structure =====

// WordDictionary 在 Trie 外面挂了一层通配符搜索。
type WordDictionary struct {
	root Trie
}

// AddWord 把单词写进底层的 Trie。
func (d *WordDictionary) AddWord(word string) {
	d.root.Insert(word)
}

// Search 匹配 word：'.' 可以代表任意一个小写字母。
func (d *WordDictionary) Search(word string) bool {
	return d.match(&d.root, word, 0)
}

// match 从 node 出发递归匹配 word[i:]；遇到 '.' 就把 26 个分支都试一遍。
func (d *WordDictionary) match(node *Trie, word string, i int) bool {
	if i == len(word) {
		return node.word != ""
	}
	if word[i] == '.' {
		for k := 0; k < 26; k++ {
			if node.children[k] != nil && d.match(node.children[k], word, i+1) {
				return true
			}
		}
		return false
	}
	next := node.children[word[i]-'a']
	return next != nil && d.match(next, word, i+1)
}

// ===== 0212 Word Search II =====

// findWords 返回所有能在网格里沿上下左右拼出来的单词。
func findWords(board [][]byte, words []string) []string {
	root := &Trie{}
	for _, w := range words {
		root.Insert(w)
	}
	out := []string{}
	used := make([][]bool, len(board))
	for i := range used {
		used[i] = make([]bool, len(board[0]))
	}
	var dfs func(r, c int, node *Trie)
	dfs = func(r, c int, node *Trie) {
		ch := board[r][c]
		child := node.children[ch-'a']
		if child == nil {
			return // 不是任何单词的前缀，剪枝
		}
		if child.word != "" {
			out = append(out, child.word)
			child.word = "" // 同一个单词只报一次
		}
		used[r][c] = true
		for _, d := range dirs {
			nr, nc := r+d[0], c+d[1]
			if nr < 0 || nr >= len(board) || nc < 0 || nc >= len(board[0]) || used[nr][nc] {
				continue
			}
			dfs(nr, nc, child)
		}
		used[r][c] = false
	}
	for r := range board {
		for c := range board[r] {
			dfs(r, c, root)
		}
	}
	return out
}

// dirs 是四个方向：上、下、左、右。
var dirs = [4][2]int{{-1, 0}, {1, 0}, {0, -1}, {0, 1}}

// show 打印一条布尔查询结果，列宽对齐方便肉眼比对。
func show(op, arg string, v bool) {
	fmt.Printf("    %-11s %-8q = %v\n", op, arg, v)
}

func main() {
	fmt.Println("=== 0208 Implement Trie (Prefix Tree) (Medium) ===")
	tr := &Trie{}
	tr.Insert("apple")
	show("search", "apple", tr.Search("apple"))
	show("search", "app", tr.Search("app"))
	show("startsWith", "app", tr.StartsWith("app"))
	tr.Insert("app")
	show("search", "app", tr.Search("app"))
	show("search", "ap", tr.Search("ap"))
	fmt.Println("=== 0211 Design Add and Search Words Data Structure (Medium) ===")
	d := &WordDictionary{}
	for _, w := range []string{"bad", "dad", "mad"} {
		d.AddWord(w)
	}
	show("search", "pad", d.Search("pad"))
	show("search", ".ad", d.Search(".ad"))
	show("search", "b..", d.Search("b.."))
	show("search", "...", d.Search("..."))
	fmt.Println("=== 0212 Word Search II (Hard) ===")
	for _, c := range [][]string{{"oaan/etae/ihkr/iflv", "oath pea eat rain"}, {"a", "aa"}} {
		var board [][]byte
		for _, row := range strings.Split(c[0], "/") {
			board = append(board, []byte(row))
		}
		words := strings.Fields(c[1])
		got := findWords(board, words)
		sort.Strings(got)
		fmt.Printf("  board=%s words=%v -> %v\n", c[0], words, got)
	}
}

5. 变体与边界 ​

  1. 前缀计数与自动补全：要多改的是「节点上挂什么」——加一个计数，插入时沿途 +1，查前缀读末节点的计数，再按计数排序输出候选。
  2. 多模式同时匹配（Aho-Corasick）：要多改的是「匹配哪一头」——0208 一次只查一个串，自动机把所有词的 fail 指针织成一张图，一次扫描找出所有命中；词库上万且要同时搜时收益最大。
  3. 0211 的其它通配符：要多改的是「遇到特殊字符怎么办」——? 匹配一个、* 匹配零到多个，* 就不能只靠分叉递归，得配回溯或 DP。
  4. 0212 的反向 trie：要多改的是「建树的方向」——把词倒着建 trie，DFS 时从终点往回拼，某些词库上剪枝更早。
  5. 压缩 trie（radix tree）：要多改的是「节点粒度」——把单链路径压成一个节点加一段字符串，节点数从 O(总字符数) 降到 O(词数)，但查前缀要退化成字符串比较。

6. 常见错误 ​

  1. Search 不查词标记 → 插入 apple 后 search("app") 返回 true。改法：走到末节点后必须要求它是一个完整单词。
  2. 把 . 当成普通字符直接下行 → 0211 直接漏解。改法：. 必须分叉枚举 26 个孩子。
  3. 把 . 当成正则（匹配任意长度） → search("pad") 在 bad/dad/mad 里被误判成 true。改法：. 只匹配一个字符，长度对不上直接 false。
  4. 0212 忘了 child.word = "" → 同一个词被重复输出，aa 这类有多条拼法的词尤其明显。改法：命中后立刻清空标记。
  5. 0212 忘了 used[r][c] = false 回溯 → 同一格被重复使用，拼出本不该存在的词。改法：回溯时复位标记。
