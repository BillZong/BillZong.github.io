17 位运算与数学 ​

把整数当二进制看：异或消掉成对的，与与移位把进位传下去。 适合：只出现一次、位掩码判定、整除与质因子判定。

1. 场景 ​

输入是一堆整数（有时只有一个），输出往往也只是一个整数或一个布尔值。决定解法的不是数据规模，而是约束里那几句话：「除一个元素外每个都恰好出现两次」（0136）说明答案可以被「消掉」；「不许用 +」（0371）说明加法得拆成位操作；「n 在 int32 内」（0342）说明位掩码的宽度是定死的；「质因子只含 2、3、5，1 算丑数」（0263）说明答案是「除干净之后剩下什么」。

认出这类题的信号：题面里出现「恰好出现 k 次」「只能使用位运算」「是不是 2 的幂 / 4 的幂」「质因子只包含……」。此时先别急着上哈希表，先问一句：这个整数的性质能不能编码进它的二进制位里？

2. 核心机制 ​

位运算能解这类题，是因为整数的二进制位本身就是一张状态表：每一位独立地记录 0 或 1，位运算就是这张表上的并行布尔运算。于是「整体满足某个性质」可以被拆成「每一位满足某个性质」，而异或、与、移位刚好覆盖了最常用的三种整体性质。

异或是无进位加法。 逐位看两个整数，只有「两位都是 1」的地方才需要额外处理，其余位的和就是两位的异或。异或的三条性质也由此而来：同一个数异或自己等于把自己加两遍（不进位），结果是 0。所以「其余元素成对出现」就是「两两异或抵消为 0」，0136 只要一行 XOR 就能解决。而 0371 要真算出 a+b，就得把异或缺的进位补回来——进位恰好发生在「两位都是 1」的地方，也就是 a & b，左移一位就是这一轮要补的进位。

位掩码是一次问一串位。 掩码的某一位是 1，就代表「我关心这一位」。0342 用 n & (n-1) == 0 问「是不是只有一个 1」，再用 n & 0x5555… 问「这个 1 落在偶数位号上吗」，两个掩码各问一件事，答案就唯一确定了。

数论题则是把条件翻译成因子结构。 0263 的「质因子只含 2、3、5」等价于「把 2、3、5 除干净后剩下 1」。这一层不用位运算，但思路一致：先圈出「坏因子」，逐个剔除，最后看剩什么。

0371 的进位链用 7+1 走一遍最直观（下面每一行是一次递归调用）：

轮次a（无进位的和）b（待补的进位）这一步发生了什么
00111 (7)0001 (1)初始
10110 (6)0010 (2)低位 1+1，向上进一位
20100 (4)0100 (4)进位撞上 4，再往上进
30000 (0)1000 (8)一路进到最高位
41000 (8)0000 (0)b 归零，收工，答案是 8

3. 套路清单 ​

套路做法复杂度备注
异或消成对全数组 XOR 一次，x^x=0 让成对的抵消时间 O(n)，空间 O(1)前提是「其余元素各出现偶数次」；出现 3 次要换成位计数
位掩码查位n & (n-1) == 0 判「只有一个 1」；n & 掩码 != 0 判「某类位上有 1」时间 O(1)，空间 O(1)掩码宽度必须覆盖 int 宽度；n > 0 不能省
位运算模拟加法a+b = (a^b) + ((a&b)<<1)，递归到进位为 0时间 O(位数)，栈 O(位数)递推式里不能出现 +；负数靠补码自然成立
快速幂指数按二进制拆，底数逐次平方时间 O(log n)，空间 O(1)负指数要先取倒数
状态压缩用整数的二进制位表示「选了哪些子集」时间 O(状态数 × 转移数)状态数是 2^n，n > 20 就别硬压
试除判因子把「允许的质因子」逐个除干净，剩下必须是 1时间 O(log n)，空间 O(1)先挡 n <= 0，否则 0 会死循环；1 按约定也算
判 2 的幂 / 4 的幂2 的幂：n>0 && n&(n-1)==0；4 的幂再加「唯一的 1 在偶数位号」时间 O(1)，空间 O(1)掩码 0x5555… 只在偶数位号上是 1

4. Go 实现 ​

四道题共用一条主线：把整数的性质翻译成二进制位的性质，再挑一个位运算去问。4.1–4.4 给的是片段，4.5 是可直接 go run 的完整程序。

4.1 0136 Single Number（Easy） ​

题目要点：给一个非空整数数组，除一个元素外其余元素都恰好出现两次，找出那个只出现一次的元素。

教学实现

go
// SingleNumber 返回只出现一次的那个元素，其余元素都出现两次。
// 异或满足 x^x=0、x^0=x，且可交换、可结合，
// 于是重复元素两两抵消为 0，只剩下那个孤儿。
func SingleNumber(nums []int) int {
	acc := 0
	for _, v := range nums {
		acc ^= v
	}
	return acc
}

讲解：异或自带「成对抵消」的性质，把整个数组 XOR 起来，成对的元素两两湮灭成 0，只剩下那个只出现一次的。acc 初值必须是 0——0 是异或的单位元，正好承接「两两抵消后剩下的那个」，换成别的初值就会把那个初值混进答案。这里不需要任何分支去判断「这个数之前见过没有」，因为抵消是 XOR 自带的性质，不是我们维护出来的状态。负数照样成立：Go 用补码表示负数，异或只是逐位独立运算，符号位也在其中。边界在空切片：题面保证非空，真传空切片会返回 0，这恰好是「没有孤儿」时的自然结果。

运行结果

text
=== 0136 Single Number ===
case 1: nums=[2 2 1] -> 1
case 2: nums=[4 1 2 1 2] -> 4
case 3: nums=[-7 -7 3] -> 3

4.2 0371 Sum of Two Integers（Medium） ​

题目要点：实现 GetSum(a, b) 返回 a+b，但不许用 +、-，只能用位运算和递归。

教学实现

go
// GetSum 返回 a+b，全程不使用 + 号。
// 异或是「无进位加法」，与是「进位产生的地方」，
// 把进位左移一位，再把它加回无进位的和里，直到没有进位。
func GetSum(a, b int) int {
	if b == 0 {
		return a
	}
	sum := a ^ b          // 无进位的和
	carry := (a & b) << 1 // 进位左移一位
	return GetSum(sum, carry)
}

讲解：这题把加法拆成两步——异或是「无进位加法」，逐位看只有两位都是 1 的地方才需要额外处理；而「两位都是 1」这件事恰好被按位与 a & b 精确刻画，左移一位就是这一轮要补的进位，于是 a + b = (a ^ b) + ((a & b) << 1)，写成递归就是「b 装着待补的进位，b 变成 0 时进位链走完」。终止条件 b == 0 不能省，否则永远是死循环；每轮进位至少往高位挪一位，所以最多 64 轮（Go 的 int 是 64 位）就收敛，递归深度也就在 64 层以内。负数不用特殊处理：补码表示下符号位参与同样的运算，a=-1, b=1 时进位链一路传到最高位、溢出一位后归零，最终拿回 0。要小心的是别在实现里偷偷用 +——题面明令禁止，写成 a + b 等于没做题。

运行结果

text

case 1: a=1 b=2 -> 3
case 2: a=-1 b=1 -> 0
case 3: a=15 b=1 -> 16

4.3 0342 Power of Four（Easy） ​

题目要点：给一个 int32 范围内的整数 n，判断它是不是 4 的幂（即存在 x ≥ 0 使 n = 4^x）。

教学实现

go
// IsPowerOfFour 判断 n 是否为 4 的幂（4^k，k>=0）。
// 两步：① n 必须是正的 2 的幂（只有一个 1）；
// ② 这个 1 必须落在偶数位号（0、2、4……）上。
func IsPowerOfFour(n int) bool {
	if n <= 0 || n&(n-1) != 0 {
		return false
	}
	// 0x5555… 在偶数位号上是 1、在奇数位号上是 0；
	// 转成 uint64 是为了掩码宽度覆盖 Go 的 64 位 int。
	return uint64(n)&0x5555555555555555 != 0
}

讲解：4 的幂是 2 的幂里「唯一那个 1 落在偶数位号」的那一半，所以两步判定各管一件事。第一步 n&(n-1) == 0 是经典的「只有一个 1」判据：减一会把最低位的 1 变成 0、把它右边的 0 全变成 1，只有原来恰好一个 1 时结果才全 0；但这一步挡不住 0（0 & -1 == 0 也成立），所以必须先用 n <= 0 挡掉。第二步 n & 0x5555… 问的是「那个 1 在不在偶数位号上」：掩码 0x55555555 的二进制是 0101 0101…，偶数位号是 1、奇数位号是 0，于是 2、8、32（1 在奇数位号）判 false，1、4、16、64（1 在偶数位号）判 true。掩码宽度必须覆盖 int 的宽度：教学版转成 uint64 再与 64 位掩码相与，仓库版的 32 位掩码只在题面 int32 值域内成立——n 一旦能到 2^32，32 位掩码会把真答案 2^32 误判成 false，demo 第 5 组用例 n=4294967296（2^32，已超出题面 int32 约束）之所以还是 true，靠的就是 64 位掩码。顺带记住 Go 的移位边界：1 << 32 作为无类型常量在 64 位 int 上是 2^32，但常量写死成 uint32(1) << 32 会编译期就报「constant overflows uint32」，改成运行期移位（x := uint32(1); x << 32）才得到 0——移位次数 ≥ 类型位宽时结果为 0。

case 4: n=1 -> true
case 5: n=4294967296 -> true

4.4 0263 Ugly Number（Easy） ​

题目要点：给一个 int32 范围内的整数 n，判断它是不是丑数——正整数且质因子只含 2、3、5，约定 1 也是丑数。

教学实现

go
// IsUgly 判断 n 的质因子是否只包含 2、3、5（约定 1 也是丑数）。
// 把这三个因子除到不能再除，剩下的必须是 1。
func IsUgly(n int) bool {
	if n <= 0 {
		return false
	}
	for _, p := range []int{2, 3, 5} {
		for n%p == 0 {
			n /= p
		}
	}
	return n == 1
}

讲解：丑数的定义是「质因子只含 2、3、5」，等价地说就是「把这三个因子除到不能再除，剩下的必须是 1」——剩下的如果大于 1，就一定含着一个不在 {2,3,5} 里的质因子。n <= 0 必须挡在最前面，而且不是形式上的：n=0 时 0 % 2 == 0 永远成立，n /= 2 之后还是 0，这个循环根本不会结束。1 是丑数是题面的约定、不是推导出来的结论——它没有质因子，除不掉任何东西，最后 n == 1 自然成立。负数同样先挡掉，题面只要正整数。每次除法至少把 n 减半，所以时间复杂度是 O(log n)、空间 O(1)。除的顺序换成 5、3、2 结果一样，因为这三个数互质。

运行结果

text
=== 0263 Ugly Number ===
case 1: n=6 -> true
case 2: n=14 -> false
case 3: n=1 -> true
case 4: n=-1 -> false

4.5 完整可运行示例 ​

下面这份程序可直接 go run（只用标准库）。它包含本篇 4.1–4.4 的全部教学实现——代码与上面逐字一致（含注释）——以及覆盖全部用例的 main。

go
package main

import "fmt"

// SingleNumber 返回只出现一次的那个元素，其余元素都出现两次。
// 异或满足 x^x=0、x^0=x，且可交换、可结合，
// 于是重复元素两两抵消为 0，只剩下那个孤儿。
func SingleNumber(nums []int) int {
	acc := 0
	for _, v := range nums {
		acc ^= v
	}
	return acc
}

// GetSum 返回 a+b，全程不使用 + 号。
// 异或是「无进位加法」，与是「进位产生的地方」，
// 把进位左移一位，再把它加回无进位的和里，直到没有进位。
func GetSum(a, b int) int {
	if b == 0 {
		return a
	}
	sum := a ^ b          // 无进位的和
	carry := (a & b) << 1 // 进位左移一位
	return GetSum(sum, carry)
}

// IsPowerOfFour 判断 n 是否为 4 的幂（4^k，k>=0）。
// 两步：① n 必须是正的 2 的幂（只有一个 1）；
// ② 这个 1 必须落在偶数位号（0、2、4……）上。
func IsPowerOfFour(n int) bool {
	if n <= 0 || n&(n-1) != 0 {
		return false
	}
	// 0x5555… 在偶数位号上是 1、在奇数位号上是 0；
	// 转成 uint64 是为了掩码宽度覆盖 Go 的 64 位 int。
	return uint64(n)&0x5555555555555555 != 0
}

// IsUgly 判断 n 的质因子是否只包含 2、3、5（约定 1 也是丑数）。
// 把这三个因子除到不能再除，剩下的必须是 1。
func IsUgly(n int) bool {
	if n <= 0 {
		return false
	}
	for _, p := range []int{2, 3, 5} {
		for n%p == 0 {
			n /= p
		}
	}
	return n == 1
}

func main() {
	fmt.Println("=== 0136 Single Number ===")
	for i, nums := range [][]int{
		{2, 2, 1},
		{4, 1, 2, 1, 2},
		{-7, -7, 3},
	} {
		fmt.Printf("case %d: nums=%v -> %d\n", i+1, nums, SingleNumber(nums))
	}

	fmt.Println("=== 0371 Sum of Two Integers ===")
	for i, c := range [][2]int{
		{1, 2},
		{-1, 1},
		{15, 1},
	} {
		fmt.Printf("case %d: a=%d b=%d -> %d\n", i+1, c[0], c[1], GetSum(c[0], c[1]))
	}

	fmt.Println("=== 0342 Power of Four ===")
	for i, n := range []int{16, 5, 8, 1, 1 << 32} {
		fmt.Printf("case %d: n=%d -> %v\n", i+1, n, IsPowerOfFour(n))
	}

	fmt.Println("=== 0263 Ugly Number ===")
	for i, n := range []int{6, 14, 1, -1} {
		fmt.Printf("case %d: n=%d -> %v\n", i+1, n, IsUgly(n))
	}
}

5. 变体与边界 ​

  1. 出现次数从 2 变成 3：0136 的 XOR 只能消掉偶数次；0137 Single Number II（Medium） 换成「按二进制位统计 1 的个数、对 3 取模」，0260 Single Number III（Medium） 则是「两个孤儿」，先全部异或再按最低的 1 位分成两组分别异或。
  2. 位掩码的宽度与位号：只判「是不是 2 的幂」是 0231 Power of Two（Easy）；数 1 的个数是 0191 Number of 1 Bits（Easy）；逐位搬运是 0190 Reverse Bits（Easy）。这三题共用「掩码宽度 = int 宽度」这条约束，只是问的位不同。
  3. 进位链反过来就是借位链：减法同样能用位运算做，a - b = a + (^b) + 1，把 ^b 代入 0371 的递推即可；多步递推则对应 0371 的迭代版。
  4. 丑数家族的判定与生成：0263 是判定，0264 Ugly Number II（Medium） 是生成前 n 个（DP 三指针或最小堆），0313 Super Ugly Number（Medium） 把质因子集合换成任意给定集合——判定版是生成版的「单点」。
  5. 博弈与快速幂也吃二进制：0292 Nim Game（Easy） 的「先手必赢 ⟺ 存在非零的 1 位」、0050 Pow(x, n)（Medium） 的「指数按二进制拆」，都是同一套「把性质拆到位上」的思路。

6. 常见错误 ​

  1. 0263 忘了先挡 0：0 % 2 == 0 永远成立，n /= 2 之后还是 0，这个 for 循环根本停不下来；n <= 0 必须写在最前面。
  2. 0371 在实现里偷偷用 +：写成 return a + b 或者用 sum + carry 做中间变量，题面明令禁止，这等于没做题；递推式只能用 ^、&、<<。
  3. 0342 忘了 n > 0：0 & (0-1) == 0 也成立，不挡掉 0 就会把 0 判成 4 的幂。
  4. 0342 掩码宽度不够：32 位掩码 0x55555555 只覆盖低 32 位，n 超过 2^31 时像 2^32 这种真答案会被误判成 false；掩码宽度必须覆盖 int 宽度，仓库版只是靠题面 int32 的约束才安全。
  5. 右移带符号：n >> 1 对负数是算术右移（补符号位），要「取高位」必须先转成无符号类型再移，uint32(n) >> 1 才是逻辑右移。
  6. 1 << k 的边界：常量移位和运行期移位是两回事。1 << 32 作为无类型常量在 64 位 int 上是 2^32；但 uint32(1) << 32 是常量表达式，编译期就报「constant overflows uint32」；写成变量 x := uint32(1); x << 32 才是运行期的 0（移位次数 ≥ 类型位宽时结果为 0）。1 << 63 赋给 int 同理编译不过，只有 int64(1) << 63 这种运行期移位才会绕回 MinInt64。
