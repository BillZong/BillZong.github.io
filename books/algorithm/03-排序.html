03 排序 ​

本质：把数据按全序排好，让「相邻」变成可用的信息源。 适合：需要第 K 大/小、要按位次处理、要排序后相邻配对。

1. 场景 ​

输入是一维数组，输出要么是排好的数组，要么只依赖次序关系：第 K 大、相邻间距、逆序对数。

决定性条件藏在约束里：值域有限（0075 只有 0/1/2）、要求原地（O(1) 额外空间）、或者写死了时间上限（0164 限 O(n)、0215 限平均 O(n)）。

认出信号：题面出现「第 K 大」「相邻」「间距」「逆序」，或者约束写着 O(n)——后者等于宣布不许用比较排序。动手前先问一句：真的要完整排序吗？多数题只要次序关系的一小块。

2. 核心机制 ​

排序之所以是公共零件，是因为它把「任意两个元素谁在前」变成一条全序链。链一旦建好，「相邻」就有了意义：间距、逆序对、差分都能直接读出来。

但比较排序的代价是 Ω(n log n)。题目限 O(n)（0164）或者只要第 K 大（0215）时，必须绕开「排完整个数组」：前者用值域换比较（桶排序），后者用分治换比较（快选）。

另一条路是把排序拆成「分」和「治」。归并排序的合并步骤天然把答案分成三块：都在左半、都在右半、跨左右，跨左右的那些正是逆序对要数的东西——排序顺手就把统计做完了。三路划分（0075）是另一个方向：值域只有三档时不需要比较，只需要判断「这个值属于哪一类」，一次扫描、三个指针就把数组切成 0 段、1 段、2 段。底层直觉是：排序不是「把数排整齐」这个动作，而是「用某种规则建立次序关系」这个结构——规则可以是比较、值域分桶或下标定位，选哪种取决于题目限制了哪一条。

3. 套路清单 ​

套路做法复杂度备注
三路划分（荷兰国旗）三个指针 lo/hi/i：遇 0 与 lo 交换并双双右移，遇 2 与 hi 交换且 i 不动，遇 1 只右移O(n) / O(1)值域只有少数几档；遇 2 换来的值还没检查，i 绝不能前进
计数排序第一遍数每个值出现几次，第二遍按次数覆写数组O(n+k) / O(k)值域 k 很小才划算；比一趟三路划分多扫一遍
快选（Quickselect）选 pivot 划分后，只递归进包含第 K 个元素的那一半，另一半直接丢弃期望 O(n) / O(1)静态数组只要一个次序位置时用；最坏 O(n²)
大小为 K 的小根堆遍历时维护 K 个候选，堆顶就是第 K 大O(n log K) / O(K)流式或多次查询用堆；K 接近 n 时不如快选
归并排序顺带计数合并时两半皆有序，用一个只前进的指针统计左半中满足条件的个数O(n log n) / O(n)条件形如 left > c×right 且 c≥1 时，c×right 随 j 不减，指针才不回退
桶排序 + 鸽巢原理桶宽取 max(1,(max-min)/(n-1))，每桶只留 min/max，扫非空桶求最大跨桶差O(n) / O(n)桶宽千万别再多加 1；值域窄时桶会退化成 1 个

4.1 0075 Sort Colors（Medium） ​

题目要点：数组只含 0/1/2，原地排成 0 段、1 段、2 段，额外空间 O(1)。

教学实现

go
// sortColors 原地把 nums 排成 0...0 1...1 2...2。
func sortColors(nums []int) {
	lo, hi, i := 0, len(nums)-1, 0
	for i <= hi {
		switch nums[i] {
		case 0:
			nums[lo], nums[i] = nums[i], nums[lo]
			lo++
			i++
		case 2:
			nums[hi], nums[i] = nums[i], nums[hi]
			hi--
		default: // 1
			i++
		}
	}
}

讲解：值域只有三档，排序退化成「分类」，不需要比较，只需要知道这个值该放哪一段。lo 指向下一个 0 的位置，hi 指向下一个 2 的位置，i 是扫描位，循环不变量是 [0,lo) 全是 0、(hi,n) 全是 2。遇 2 时 i 绝不能前进，因为换到 nums[i] 的旧值还没被检查过，可能仍是 2；遇 0 时 i 可以前进，因为交换过来的旧值来自 lo，而 lo ≤ i，那一格早就检查过了。边界不用特判：空数组时 hi 是 -1，循环条件 i <= hi 直接不成立。

运行结果

text
[2 0 2 1 1 0] -> [0 0 1 1 2 2]
[2 0 1] -> [0 1 2]
[] -> []

仓库实现：0075-sort-colors/solution.go

4.2 0215 Kth Largest Element in an Array（Medium） ​

题目要点：返回数组里第 k 大的元素，k 从 1 开始，重复值各算一份；要求平均 O(n)。

教学实现

go
// findKthLargest 返回第 k 大元素，k 从 1 开始计数。
func findKthLargest(nums []int, k int) int {
	if k < 1 || k > len(nums) {
		return 0
	}
	h := &intMinHeap{}
	heap.Init(h)
	for _, x := range nums {
		if h.Len() < k {
			heap.Push(h, x)
		} else if x > (*h)[0] {
			heap.Pop(h)
			heap.Push(h, x)
		}
	}
	return (*h)[0]
}

讲解：要的是「第 k 大」，所以堆顶必须是候选里最小的那个，用小根堆而不是大根堆弹 k 次；配套的堆类型 intMinHeap 与它的五个 heap.Interface 方法见 4.5 的完整程序。堆的不变量是：里面始终装着「目前见过的最大的 k 个元素」，堆顶是其中最小者，也就是当前的第 k 大。x 不大于堆顶时直接跳过——它既挤不进前 k 名，也不会让答案变好，这条严格大于的判断同时保证了重复值各算一份。边界上 k 等于数组长度时堆装满全部，堆顶就是最小值；k 等于 1 时堆顶就是最大值；k 不合法时返回 0。代价是 O(k) 空间：数组静态、只要一个次序位置时，快选的期望 O(n) 更合适。

运行结果

text
[3 2 1 5 6 4] k=2 -> 5
[3 2 3 1 2 4 5 5 6] k=4 -> 4
[2 2 2] k=3 -> 2
random(n=10000, seed=20261028) k=137 -> 9702

4.3 0493 Reverse Pairs（Hard） ​

题目要点：统计满足 i < j 且 nums[i] > 2*nums[j] 的下标对数量，n 到 5×10^4。

教学实现

go
// countPairs 分治计数：左半内部 + 右半内部 + 跨左右。
func countPairs(a, buf []int, lo, hi int) int {
	if lo >= hi {
		return 0
	}
	mid := lo + (hi-lo)/2
	cnt := countPairs(a, buf, lo, mid) + countPairs(a, buf, mid+1, hi)
	i := lo // 左半有序，2*a[j] 随 j 不减，i 只前进不回退
	for j := mid + 1; j <= hi; j++ {
		for i <= mid && a[i] <= 2*a[j] {
			i++
		}
		cnt += mid - i + 1
	}
	merge(a, buf, lo, mid, hi)
	return cnt
}

讲解：归并排序天然适合数逆序对，因为递归把区间劈成两半后，答案可以拆成「左半内部 + 右半内部 + 跨左右」，前两项递归给，第三项在合并时顺手算；入口 reversePairs 与合并用的 merge 见 4.5 的完整程序。跨左右的计数靠一个不变量：左半已经升序，右半的 j 递增时 2a[j] 不减，所以左指针 i 只需要前进，一旦 a[i] > 2a[j]，左半剩下的元素全部满足条件，一次加 mid-i+1 即可。若对每个 j 都从头扫左半，就退化成 O(n²)——i 不回退正是本题唯一的卡点。边界上 i 最多停在 mid+1，所以 mid-i+1 不会变负；2*a[j] 也不用担心溢出，Go 的 int 在 64 位平台就是 64 位。

运行结果

text
[1 3 2 3 1] -> 2
[2 4 3 5 1] -> 3
[-2 -4] -> 1

仓库实现：0493-reverse-pairs/solution.go

4.4 0164 Maximum Gap（Hard） ​

题目要点：返回数组排序后相邻元素的最大间距，题目明写要 O(n) 时间、O(n) 空间。

教学实现

go
// maximumGap 返回排序后相邻元素的最大间距。
func maximumGap(nums []int) int {
	if len(nums) < 2 {
		return 0
	}
	lo, hi := nums[0], nums[0]
	for _, v := range nums[1:] {
		lo, hi = min(lo, v), max(hi, v)
	}
	size := max(1, (hi-lo)/(len(nums)-1)) // 桶宽取平均间距，且至少为 1
	cnt := (hi-lo)/size + 1
	bmin := make([]int, cnt)
	bmax := make([]int, cnt)
	for i := range bmin {
		bmin[i], bmax[i] = hi+1, lo-1 // 空桶哨兵
	}
	for _, v := range nums {
		idx := (v - lo) / size
		bmin[idx] = min(bmin[idx], v)
		bmax[idx] = max(bmax[idx], v)
	}
	gap, prev := 0, bmax[0]
	for i := 1; i < cnt; i++ {
		if bmin[i] <= bmax[i] {
			gap = max(gap, bmin[i]-prev)
			prev = bmax[i]
		}
	}
	return gap
}

讲解：比较排序是 Ω(n log n)，题目限 O(n) 就必须换规则，于是用值域换比较。鸽巢原理给出关键下界：n 个数最多 n-1 个相邻间隔，平均是 (max-min)/(n-1)，所以最大间隔至少不小于它。桶宽取 max(1,(max-min)/(n-1)) 之后，桶内任意两数之差都小于桶宽，答案一定跨桶出现，于是每个桶只保留 min 和 max 就够，最后线性扫一遍非空桶求相邻桶之间的最大跳。边界全被公式自然覆盖：少于两个元素提前返回 0；所有数相等时 hi 等于 lo，桶数退化成 1、扫描循环根本不执行，答案自然是 0。桶宽千万别再多加一个 1，否则 n=2 时两个数会挤进同一个桶，答案直接变成 0。

运行结果

text
[3 6 9 1] -> 3
[10] -> 0
[1 1000000000] -> 999999999

4.5 完整可运行程序 ​

完整程序：上面四段实现加上缺失的辅助类型与合并函数、再配一段 main，就是一个覆盖四道题的完整程序，可以直接 go run . 跑；下面的文本块是它跑出来的全部输出，也是各节「运行结果」的出处。

go
package main

import (
	"container/heap"
	"fmt"
	"math/rand"
)

func sortColors(nums []int) {
	lo, hi, i := 0, len(nums)-1, 0
	for i <= hi {
		switch nums[i] {
		case 0:
			nums[lo], nums[i] = nums[i], nums[lo]
			lo++
			i++
		case 2:
			nums[hi], nums[i] = nums[i], nums[hi]
			hi--
		default: // 1
			i++
		}
	}
}

type intMinHeap []int

func (h intMinHeap) Len() int           { return len(h) }
func (h intMinHeap) Less(i, j int) bool { return h[i] < h[j] }
func (h intMinHeap) Swap(i, j int)      { h[i], h[j] = h[j], h[i] }
func (h *intMinHeap) Push(x any)        { *h = append(*h, x.(int)) }
func (h *intMinHeap) Pop() any {
	old := *h
	x := old[len(old)-1]
	*h = old[:len(old)-1]
	return x
}

func findKthLargest(nums []int, k int) int {
	if k < 1 || k > len(nums) {
		return 0
	}
	h := &intMinHeap{}
	heap.Init(h)
	for _, x := range nums {
		if h.Len() < k {
			heap.Push(h, x)
		} else if x > (*h)[0] {
			heap.Pop(h)
			heap.Push(h, x)
		}
	}
	return (*h)[0]
}

func reversePairs(nums []int) int {
	buf := make([]int, len(nums))
	return countPairs(nums, buf, 0, len(nums)-1)
}

func countPairs(a, buf []int, lo, hi int) int {
	if lo >= hi {
		return 0
	}
	mid := lo + (hi-lo)/2
	cnt := countPairs(a, buf, lo, mid) + countPairs(a, buf, mid+1, hi)
	i := lo // 左半有序，2*a[j] 随 j 不减，i 只前进不回退
	for j := mid + 1; j <= hi; j++ {
		for i <= mid && a[i] <= 2*a[j] {
			i++
		}
		cnt += mid - i + 1
	}
	merge(a, buf, lo, mid, hi)
	return cnt
}

func merge(a, buf []int, lo, mid, hi int) {
	i, j, k := lo, mid+1, lo
	for i <= mid && j <= hi {
		if a[i] <= a[j] {
			buf[k] = a[i]
			i++
		} else {
			buf[k] = a[j]
			j++
		}
		k++
	}
	if i <= mid {
		copy(buf[k:], a[i:mid+1])
	} else {
		copy(buf[k:], a[j:hi+1])
	}
	copy(a[lo:hi+1], buf[lo:hi+1])
}

func maximumGap(nums []int) int {
	if len(nums) < 2 {
		return 0
	}
	lo, hi := nums[0], nums[0]
	for _, v := range nums[1:] {
		lo, hi = min(lo, v), max(hi, v)
	}
	size := max(1, (hi-lo)/(len(nums)-1)) // 桶宽取平均间距，且至少为 1
	cnt := (hi-lo)/size + 1
	bmin := make([]int, cnt)
	bmax := make([]int, cnt)
	for i := range bmin {
		bmin[i], bmax[i] = hi+1, lo-1 // 空桶哨兵
	}
	for _, v := range nums {
		idx := (v - lo) / size
		bmin[idx] = min(bmin[idx], v)
		bmax[idx] = max(bmax[idx], v)
	}
	gap, prev := 0, bmax[0]
	for i := 1; i < cnt; i++ {
		if bmin[i] <= bmax[i] {
			gap = max(gap, bmin[i]-prev)
			prev = bmax[i]
		}
	}
	return gap
}

func main() {
	for _, in := range [][]int{{2, 0, 2, 1, 1, 0}, {2, 0, 1}, {}} {
		cp := append([]int(nil), in...)
		sortColors(cp)
		fmt.Printf("%v -> %v\n", in, cp)
	}
	numsList := [][]int{{3, 2, 1, 5, 6, 4}, {3, 2, 3, 1, 2, 4, 5, 5, 6}, {2, 2, 2}}
	ks := []int{2, 4, 3}
	for i, in := range numsList {
		fmt.Printf("%v k=%d -> %d\n", in, ks[i], findKthLargest(in, ks[i]))
	}
	rng := rand.New(rand.NewSource(20261028))
	big := make([]int, 10000)
	for i := range big {
		big[i] = rng.Intn(20001) - 10000
	}
	fmt.Printf("random(n=%d, seed=20261028) k=137 -> %d\n", len(big), findKthLargest(big, 137))
	for _, in := range [][]int{{1, 3, 2, 3, 1}, {2, 4, 3, 5, 1}, {-2, -4}} {
		cp := append([]int(nil), in...)
		fmt.Printf("%v -> %d\n", in, reversePairs(cp))
	}
	for _, in := range [][]int{{3, 6, 9, 1}, {10}, {1, 1000000000}} {
		fmt.Printf("%v -> %d\n", in, maximumGap(in))
	}
}

5. 变体与边界 ​

  1. 只要第 K 大且数组静态、只问一次：快选（随机 pivot）期望 O(n)；流式输入或要反复查询第 K 大，才保留大小为 K 的堆。
  2. 计数条件从 a[i] > a[j] 变成 a[i] > c*a[j]：c ≥ 1 时归并计数照样成立，因为 c*a[j] 随 j 不减；c 为负数时单调性反转，左指针必须回退，得换成树状数组或有序集合。
  3. 只要「排序后相邻」的最大差值且题目限 O(n)：桶排序（0164），桶宽由 (max-min)/(n-1) 决定而不是由值域大小决定，值域宽到 10^9 也不影响桶数。
  4. 多关键字排序（先按分数降序、同分按年龄升序）：显式写比较器，别依赖排序算法的稳定性——Go 的 sort.Slice 不稳定，要稳定得用 sort.SliceStable。

6. 常见错误 ​

  1. 三路划分遇 2 之后把 i 也前进了：换过来的值还没检查，结果错位。改法：只让 hi 退一格，i 原地不动。
  2. 归并计数时对每个 j 都从头扫左半：复杂度掉回 O(n²)。改法：利用左半有序让 i 跨 j 只前进。
  3. 桶排序的桶宽写成 (max-min)/(n-1)+1：多出的 1 让桶变宽，n=2 时两个数挤进同一个桶，答案变成 0。改法：严格用 max(1,(max-min)/(n-1))，别自作主张加 1。
  4. 第 K 大用大根堆弹 k 次：多出 O(k log n) 的弹出开销，k 大时明显慢。改法：维护大小为 k 的小根堆，堆顶就是答案。
  5. 桶扫描时拿桶内 min/max 相减：桶内差恒小于桶宽，不是答案。改法：用「上一个非空桶的 max」减「当前非空桶的 min」，prev 初值取 bucketMax[0]。
