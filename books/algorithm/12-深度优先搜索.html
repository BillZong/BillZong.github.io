12 深度优先搜索 ​

一条路走到尽头，走不动了就退回上一个岔口。 适合：连通块计数、枚举所有方案、路径搜索、依赖判环。

1. 场景 ​

DFS 的输入形态差别极大——二维网格、邻接表、字符串、棋盘；输出却只有两类：一个计数或布尔值，或者一份穷举出来的解集。

认出信号有两条：题目要「把所有方案枚举完整」（N 皇后的每一种摆法、回文分割的每一种切法），或者要「数一数有几块、有没有环」（岛屿个数、课程能不能学完）。决定性条件藏在约束里：0200 的 m, n ≤ 300 意味着一次染色最深到九万格，递归版在 Go 里不现实；0131 的 |s| ≤ 16 意味着解数上界 2^15，可以全枚举而不是求最少切分；0207 的课程数 2000、边数 5000 意味着判环只能一次线性扫描。共同点是：约束都在说「别硬算」，但硬算的是解空间，不是输入规模。

2. 核心机制 ​

DFS 的状态只有两样：现在站在哪（当前位置）和做过哪些选择（路径）。递归体永远只做两件事：往前走一步，走不动就退回一步。所谓「回退」，在不同题型里由不同的东西承担，这是本文的主线。

三种「回退」的差别是这一整篇的关键。0200 里没有选择可撤销：格子一旦被染成水，就再也不用回头看它。0131 里必须撤销：不撤销的话，切「a」这条分支留下的痕迹会污染切「aa」的分支，两种答案会串在一起。0207 里既不能撤销也不能染色——图不是树，边可能指向祖先，所以必须多记一个「在当前递归栈上」的状态，才能把「回边」和「指向已访问的兄弟节点」区分开。

回溯的搜索空间是一棵树：内部节点是「已经做出的选择序列」，叶子是答案。以 0131 的 "aab" 为例，从空串出发可以切 "a"（再切 "a" 再切 "b"），也可以切 "aa"（再切 "b"），而 "ab" 不是回文、在这一层就被剪掉。剪枝判据必须是当前前缀的局部性质——只看总数会漏掉非法前缀。

3. 套路清单 ​

套路做法复杂度备注
连通块计数网格/邻接表上 DFS，每撞见一个未访问节点就 +1，再把整块染色时间 O(V+E)，空间 O(V)递归深度可能达 m×n（0200 到九万层），改用显式栈；就地染色会改调用方的数据
回溯枚举维护 path，放置 → 递归 → 撤销放置时间 O(解数 × 路径长)，空间 O(深度)撤销必须成对，否则不同分支互相污染
回溯剪枝当前前缀不合法就跳过（N 皇后同列同斜线、0131 非回文前缀）同上判据是前缀的局部性质，不能看总数
预处理回文表先用中心扩展算出 isPal[l*n+r]，回溯时 O(1) 判定时间 O(n²)+回溯n ≤ 16 时收益小，但代码更清楚
拓扑判环（三色）未访问/在栈上/已完成，撞见在栈上的节点即有环时间 O(V+E)，空间 O(V+E)递归返回时必须把节点染成「已完成」

四道题共用一条主线：沿着一组选择往下走，走不动就退回。4.1–4.4 给的是片段实现，4.5 是可直接 go run 的完整程序。四段实现都与仓库版做过差分对拍（固定边界用例 + 固定种子随机用例 + 暴力解 oracle），结果完全一致。

4.1 0200 Number of Islands（Medium） ​

题目要点：给一个只含 '0'/'1' 的网格，返回岛屿个数；陆地按上下左右四连通，对角不算；m, n ≤ 300。

教学实现

go
// NumIslands 统计网格里岛屿（四连通块）的个数。
func NumIslands(grid [][]byte) int {
	count := 0
	for i := range grid {
		for j := range grid[i] {
			if grid[i][j] != '1' {
				continue
			}
			count++ // 撞上没标记过的陆地 = 发现新岛屿
			stack := [][2]int{{i, j}}
			for len(stack) > 0 {
				p := stack[len(stack)-1]
				stack = stack[:len(stack)-1]
				r, c := p[0], p[1]
				if r < 0 || r >= len(grid) || c < 0 || c >= len(grid[r]) || grid[r][c] != '1' {
					continue // 越界或已染色
				}
				grid[r][c] = '0' // 就地标记兼作 visited
				stack = append(stack, [2]int{r - 1, c}, [2]int{r + 1, c}, [2]int{r, c - 1}, [2]int{r, c + 1})
			}
		}
	}
	return count
}

讲解：计数逻辑只有一句：每撞见一个没被标记过的陆地就 +1，再用 DFS 把整块连通区域染成水，染过的地方自然不会被重复计数。仓库版也是迭代 DFS，因为 300×300 全是陆地时岛屿能连成一条九万格的蛇，递归深度就等于蛇的长度。显式栈版本要注意边界判断放在弹出时而不是压入时：弹出时判则每个格子最多进栈一次，压入时判会让栈里塞满重复坐标。grid[r][c] = '0' 是就地标记兼作 visited，省下一个二维数组，代价是函数会改掉调用方的网格，测试时必须先拷贝一份。

4.2 0051 N-Queens（Hard） ​

题目要点：在 n×n 棋盘上放 n 个皇后，任意两个不能同行、同列、同斜线，返回全部不同摆法；1 ≤ n ≤ 9。

教学实现

go
// SolveNQueens 返回 N 皇后问题的全部解，每个解是 n 行棋盘。
func SolveNQueens(n int) [][]string {
	if n <= 0 {
		return [][]string{}
	}
	cols := make([]bool, n)    // 第 c 列已放皇后
	diag1 := make([]bool, 2*n) // r-c 相同（\ 方向）已占用
	diag2 := make([]bool, 2*n) // r+c 相同（/ 方向）已占用
	pos := make([]int, n)      // 第 r 行皇后所在列
	out := [][]string{}
	var dfs func(row int)
	dfs = func(row int) {
		if row == n {
			board := make([]string, n)
			for r := range board {
				board[r] = strings.Repeat(".", pos[r]) + "Q" + strings.Repeat(".", n-1-pos[r])
			}
			out = append(out, board)
			return
		}
		for c := 0; c < n; c++ {
			if cols[c] || diag1[row-c+n] || diag2[row+c] {
				continue // 同列或同对角线，换列重试
			}
			cols[c], diag1[row-c+n], diag2[row+c] = true, true, true
			pos[row] = c
			dfs(row + 1)
			cols[c], diag1[row-c+n], diag2[row+c] = false, false, false // 撤销
		}
	}
	dfs(0)
	return out
}

讲解：每行必须恰好一个皇后（否则同行冲突），所以可以按行递归，这是回溯的教科书写法。三组冲突检测各用一张布尔表：同列看 cols[c]，一条斜线上的格子 r-c 相同、另一条 r+c 相同，于是 diag1[r-c+n]、diag2[r+c] 两张长度 2n 的表覆盖所有斜线，下标加 n 是为了让 r-c 不出负数。放置时把三张表置真、递归、返回后全部置假——这一步就是「撤销」，漏掉它两个分支的皇后会互相打架。仓库版用三个 bitmask，常数更小但移位方向容易写反；这里用布尔表，是因为它把「哪条斜线」写成了可读的算式。

4.3 0131 Palindrome Partitioning（Medium） ​

题目要点：把字符串切成若干段，每段都必须是回文，返回所有切法；1 ≤ |s| ≤ 16。

教学实现

go
// Partition 返回 s 的所有回文分割方案。
func Partition(s string) [][]string {
	n := len(s)
	if n == 0 {
		return [][]string{}
	}
	// 中心扩展预处理：isPal[l*n+r] 表示 s[l..r] 是否回文
	isPal := make([]bool, n*n)
	for c := 0; c < n; c++ {
		for d := 0; d < 2; d++ { // d=0 奇数中心，d=1 偶数中心
			for l, r := c, c+d; l >= 0 && r < n && s[l] == s[r]; l, r = l-1, r+1 {
				isPal[l*n+r] = true
			}
		}
	}
	out := [][]string{}
	path := []string{}
	var dfs func(start int)
	dfs = func(start int) {
		if start == n {
			out = append(out, append([]string(nil), path...)) // 叶子处必须拷贝 path
			return
		}
		for end := start; end < n; end++ {
			if !isPal[start*n+end] {
				continue
			}
			path = append(path, s[start:end+1])
			dfs(end + 1)
			path = path[:len(path)-1] // 回溯：撤销这一步选择
		}
	}
	dfs(0)
	return out
}

讲解：切法本身就是解空间：从 start 出发逐个延长 end，凡是 s[start..end] 是回文就切一刀继续递归。难点在回文判定——每次现算一遍是 O(n)，总复杂度被拉到 O(n·2ⁿ)；先用中心扩展把整张回文表 isPal[l*n+r] 预处理出来，回溯时 O(1) 判定，中心只有奇数的 (c, c) 和偶数的 (c, c+1) 两种，从中心往外扩到字符不等为止，正好 O(n²)。第二个坑是叶子处必须拷贝 path：path 是一块共享的底层数组，后续回溯会继续改它，不拷贝的话先收到的答案会被后面的分支污染。题面约束 |s| ≤ 16 说的就是解数上界 2^15 ≈ 32k；长度到 100 就该换 0132 的最小切分 DP。

4.4 0207 Course Schedule（Medium） ​

题目要点：n 门课，prerequisites[i] = [a, b] 表示学 a 之前要先学 b，判断能否学完所有课；n ≤ 2000，边 ≤ 5000。

教学实现

go
// CanFinish 判断能否学完所有课程（本质：有向图是否有环）。
func CanFinish(numCourses int, prerequisites [][]int) bool {
	graph := make([][]int, numCourses)
	for _, p := range prerequisites {
		graph[p[1]] = append(graph[p[1]], p[0]) // 先修 p[1] → 后修 p[0]
	}
	color := make([]uint8, numCourses) // 0=未访问，1=在栈上，2=已完成
	var dfs func(u int) bool
	dfs = func(u int) bool {
		color[u] = 1
		for _, v := range graph[u] {
			if color[v] == 1 {
				return false // 撞见栈上的节点 = 回边 = 有环
			}
			if color[v] == 0 && !dfs(v) {
				return false
			}
		}
		color[u] = 2
		return true
	}
	for u := 0; u < numCourses; u++ {
		if color[u] == 0 && !dfs(u) {
			return false
		}
	}
	return true
}

讲解：把依赖画成有向图（b → a，因为 b 是 a 的前置），「能否学完」就等于「图里有没有环」——有环则依赖链首尾相接永远解不开。判环有两种写法：三色标记（本节教学版，也是仓库版）用白色未访问、灰色在当前 DFS 栈上、黑色已访问完，途中撞见灰色节点就是回边，灰色这个状态是它比二色 visited 强的地方；Kahn 拓扑排序（仓库 0207-course-schedule/other-best-answers/kahn-topological-sort.md）先算入度、把入度为 0 的点进队列，最后数处理了多少个点，少于 n 说明剩下的点都在环里。三色法要在递归返回时把节点染黑，漏了会把已经安全的节点误判成环；Kahn 法没有递归，深链依赖在递归版是栈深问题、在队列版只是一条长链。两者都是 O(V+E)，选哪个看代码组织习惯，不是性能。

5. 变体与边界 ​

  1. 网格改成八连通：0200 的邻居从四个方向扩到八个，「对角不相连」这个边界就不存在了；判定写在弹出时还是压入时不用变。
  2. 只要一个解就停：0051 找到第一个解后整棵子树都可以剪掉（回溯时不再往下递归），复杂度从「枚举全部解」降到「第一个解的搜索量」；0131 同理。
  3. 求最少切分而不是全部切法：0131 的枚举在 |s| 变大时不可行，要换成 0132 的 DP——dp[i] 是前 i 个字符的最少切分数，转移 dp[i] = min(dp[j]+1)，其中 s[j..i-1] 必须是回文。
  4. 判环换成入度法：0207 改用 Kahn 拓扑排序就不需要递归了，深链依赖（1 依赖 2 依赖 3……）在递归版是栈深问题，在队列版只是一条长链。

6. 常见错误 ​

  1. 0200 在压栈时判边界、或者干脆写递归版：压栈时判会让栈里塞满越界坐标，内存翻倍还容易漏判；300×300 全陆地时递归深度到九万，Go 里也不现实。改法：换显式栈，弹出时统一判越界与是否陆地。
  2. 0131 忘记拷贝 path：先收到的答案被后续分支污染。改法：叶子处 append([]string(nil), path...) 拷一份再入 results。
  3. 回溯忘记撤销：0051 里三张冲突表不置回 false，两个分支的皇后互相打架；0131 里 path 不回退，切法会混。改法：放置和撤销必须成对出现。
  4. 0207 三色标记漏了「返回时染黑」、或者把依赖方向画反：前者会让同一个节点被第二次访问时颜色还是灰色、误报有环（改法：color[u] = 2 放在递归返回前）；后者 graph[a] → b 等于说「学 b 之前要先学 a」，跟题面正好相反（改法：先修 b → 后修 a，画一条 b → a 的边）。
