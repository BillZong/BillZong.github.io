19 设计类 ​

把功能要求翻译成数据结构的组合，并对每个操作给出复杂度承诺。 适合：题目要你实现一个类，含多个方法，且写明了每次操作的复杂度上限。

1. 场景 ​

设计类题目的输入不是一串数据，而是一份接口契约：有哪些方法、每个方法收什么返回什么，外加「每次必须 O(1)」这类性能条款。

约束里藏着决定性条件：0146 明说 get/put 都要 O(1)，所以「每次遍历找最久未用」直接出局；0295 要在流里随时取中位数，排序一次来不及；0380 要随机取，数组下标天然满足，但删除会留洞。

信号是「让你写一个类 + 题面写明复杂度上限」，而不是「让你求出某个值」。

2. 核心机制 ​

这类题考的不是算法，是接口设计 + 数据结构组合 + 复杂度承诺。单个操作往往有多种实现，题面的性能条款直接排除掉其中最慢的那一类。

组合的套路是「各取所长」：哈希表负责按键 O(1) 定位，链表或堆负责维护顺序，两边用同一个节点指针连起来，删的时候两边同步删。

复杂度承诺要在动笔之前定下来：先想清楚每次操作要碰几个数据，再挑结构；反过来先写暴力再改，很容易写出「平均 O(1)、最坏 O(n)」的版本。

3. 套路清单 ​

套路做法复杂度备注
哈希表 + 双向链表map 记 key→节点，链表定使用顺序每次 O(1)，空间 O(cap)淘汰时要同步删 map 条目
辅助栈主栈每层同步记一个最小值每次 O(1)，空间 O(n)重复最小值也要压，否则 pop 后过期
两个堆大根堆装小的一半，小根堆装大的一半插入 O(log n)，取中位数 O(1)插入后要把堆顶搬一次回去
数组 + 下标映射map 记下标，删除时用末尾元素补洞每次 O(1)，空间 O(n)补洞后要改被搬元素的下标
计数 + 过期时间计数表加时间桶滚动每次 O(1)，空间 O(窗口)用于限流、命中率统计

4. Go 实现 ​

四题都是方法型 API：先构造对象，再逐个方法调用。教学版优先用标准库 container/list 与 container/heap，0380 则用「末尾元素补洞」的手写技巧。

4.1 0146 LRU Cache（Medium） ​

题目要点：实现固定容量的缓存，get/put 都要 O(1)；超出容量时淘汰最久未使用的键。

教学实现

go
// LRUCache 用哈希表定位节点、双向链表维护使用顺序。
type LRUCache struct {
	capacity int
	order    *list.List            // 队首 = 最近使用，队尾 = 最久未使用
	nodes    map[int]*list.Element // key -> 链表节点
}

func (c *LRUCache) Get(key int) int {
	e, ok := c.nodes[key]
	if !ok {
		return -1
	}
	c.order.MoveToFront(e)
	return e.Value.(lruEntry).val
}
func (c *LRUCache) Put(key, val int) {
	e, ok := c.nodes[key]
	if ok {
		e.Value = lruEntry{key, val}
	} else {
		e = c.order.PushFront(lruEntry{key, val})
		c.nodes[key] = e
	}
	c.order.MoveToFront(e)
	if c.order.Len() > c.capacity {
		oldest := c.order.Back()
		c.order.Remove(oldest)
		delete(c.nodes, oldest.Value.(lruEntry).key)
	}
}

讲解：哈希表负责「按键一步找到节点」，链表负责「维护使用顺序」，两者用同一个 *list.Element 连起来，删的时候必须两边同步删（链表节点类型 lruEntry 与构造器见 4.5）。 get 命中后要 MoveToFront，否则「最近使用」的语义就丢了；put 命中已有 key 只改值并移到队首，不新增条目，也就不会白白淘汰别人。

4.2 0155 Min Stack（Medium） ​

题目要点：实现一个栈，push/pop/top/getMin 每个方法都要 O(1)。

教学实现

go
// MinStack 用一个辅助栈同步记录每一层的最小值。
type MinStack struct {
	data []int // 主栈
	mins []int // 辅助栈：mins[i] 是 data[:i+1] 的最小值
}

func (s *MinStack) Push(val int) {
	s.data = append(s.data, val)
	cur := val
	if len(s.mins) > 0 && s.mins[len(s.mins)-1] < cur {
		cur = s.mins[len(s.mins)-1]
	}
	s.mins = append(s.mins, cur)
}

讲解：主栈 data 照常出入，辅助栈 mins 与它同步——每压一层就把「到这一层为止的最小值」也压一层，于是 mins 的栈顶恒为当前最小值，getMin 退化成一次取栈顶。 关键是每次都压：只在「更小」时才压的话，遇到重复最小值，真最小值被 pop 之后辅助栈顶就变成过期值；两个栈一起弹，push 与 pop 因此完全对称（Pop/Top/GetMin 见 4.5）。

4.3 0295 Find Median from Data Stream（Hard） ​

题目要点：数据流不断来整数，随时返回当前中位数。

教学实现

go
func (m *MedianFinder) AddNum(num int) {
	heap.Push(&m.lo, num)
	heap.Push(&m.hi, heap.Pop(&m.lo))
	if m.lo.Len() < m.hi.Len() {
		heap.Push(&m.lo, heap.Pop(&m.hi))
	}
}
func (m *MedianFinder) FindMedian() float64 {
	if m.lo.Len() > m.hi.Len() {
		return float64(m.lo[0])
	}
	return float64(m.lo[0]+m.hi[0]) / 2.0
}

讲解：两个堆分装上下半区：lo 是大根堆装小的一半，hi 是小根堆装大的一半，MedianFinder 与两个堆的类型定义见 4.5，只有 Less 的方向相反。 插入分三步：先压进 lo，再把 lo 的堆顶搬进 hi（保证 lo 里所有数都不大于 hi 里所有数），若此时 lo 偏小，再把 hi 的堆顶搬回 lo；于是奇数个时中位数是 lo 的堆顶，偶数个时取两个堆顶的平均。

4.4 0380 Insert Delete GetRandom O(1)（Medium） ​

题目要点：实现一个集合，insert/remove/getRandom 都要平均 O(1)。

教学实现

go
func (s *RandomizedSet) Remove(val int) bool {
	i, ok := s.idx[val]
	if !ok {
		return false
	}
	last := s.vals[len(s.vals)-1]
	s.vals[i] = last
	s.idx[last] = i
	// 顺序不能反：先写 idx[last] 再 delete(idx[val])，否则 last == val 时会漏删
	delete(s.idx, val)
	s.vals = s.vals[:len(s.vals)-1]
	return true
}

讲解：集合用两个东西表示：vals 是底层数组，存所有元素用来随机取；idx 是哈希表，记每个值在 vals 里的下标，用来按键定位（结构体与构造器见 4.5）。 删除是难点：数组中间挖洞会让随机取变慢，于是把末尾元素搬到被删位置填补空位再截掉末尾——搬的是最后一个元素，不涉及搬移后续大量元素，仍是 O(1)。

4.5 完整可运行示例 ​

下面这份程序可直接 go run（只用标准库）。它包含本篇 4.1–4.4 的全部教学实现——代码与上面逐字一致（含注释）——以及覆盖全部用例的 main。

go
package main

import (
	"container/heap"
	"container/list"
	"fmt"
	"math/rand"
)

// lruEntry 挂在链表上的条目；key 必须一起存，淘汰时才知道该删哈希表里的哪一项。
type lruEntry struct{ key, val int }

// LRUCache 用哈希表定位节点、双向链表维护使用顺序。
type LRUCache struct {
	capacity int
	order    *list.List            // 队首 = 最近使用，队尾 = 最久未使用
	nodes    map[int]*list.Element // key -> 链表节点
}

func (c *LRUCache) Get(key int) int {
	e, ok := c.nodes[key]
	if !ok {
		return -1
	}
	c.order.MoveToFront(e)
	return e.Value.(lruEntry).val
}
func (c *LRUCache) Put(key, val int) {
	e, ok := c.nodes[key]
	if ok {
		e.Value = lruEntry{key, val}
	} else {
		e = c.order.PushFront(lruEntry{key, val})
		c.nodes[key] = e
	}
	c.order.MoveToFront(e)
	if c.order.Len() > c.capacity {
		oldest := c.order.Back()
		c.order.Remove(oldest)
		delete(c.nodes, oldest.Value.(lruEntry).key)
	}
}
func NewLRUCache(capacity int) *LRUCache {
	return &LRUCache{capacity, list.New(), map[int]*list.Element{}}
}

// MinStack 用一个辅助栈同步记录每一层的最小值。
type MinStack struct {
	data []int // 主栈
	mins []int // 辅助栈：mins[i] 是 data[:i+1] 的最小值
}

func (s *MinStack) Push(val int) {
	s.data = append(s.data, val)
	cur := val
	if len(s.mins) > 0 && s.mins[len(s.mins)-1] < cur {
		cur = s.mins[len(s.mins)-1]
	}
	s.mins = append(s.mins, cur)
}
func (s *MinStack) Pop() {
	s.data = s.data[:len(s.data)-1]
	s.mins = s.mins[:len(s.mins)-1]
}
func (s *MinStack) Top() int    { return s.data[len(s.data)-1] }
func (s *MinStack) GetMin() int { return s.mins[len(s.mins)-1] }

// maxHeap 大根堆：堆顶是下半区的最大值。
type maxHeap []int

func (h maxHeap) Len() int           { return len(h) }
func (h maxHeap) Less(i, j int) bool { return h[i] > h[j] }
func (h maxHeap) Swap(i, j int)      { h[i], h[j] = h[j], h[i] }
func (h *maxHeap) Push(x any)        { *h = append(*h, x.(int)) }
func (h *maxHeap) Pop() any          { old := *h; n := len(old); v := old[n-1]; *h = old[:n-1]; return v }

type minHeap []int

func (h minHeap) Len() int           { return len(h) }
func (h minHeap) Less(i, j int) bool { return h[i] < h[j] }
func (h minHeap) Swap(i, j int)      { h[i], h[j] = h[j], h[i] }
func (h *minHeap) Push(x any)        { *h = append(*h, x.(int)) }
func (h *minHeap) Pop() any          { old := *h; n := len(old); v := old[n-1]; *h = old[:n-1]; return v }

type MedianFinder struct {
	lo maxHeap // 下半区（大根堆）
	hi minHeap // 上半区（小根堆）
}

func (m *MedianFinder) AddNum(num int) {
	heap.Push(&m.lo, num)
	heap.Push(&m.hi, heap.Pop(&m.lo))
	if m.lo.Len() < m.hi.Len() {
		heap.Push(&m.lo, heap.Pop(&m.hi))
	}
}
func (m *MedianFinder) FindMedian() float64 {
	if m.lo.Len() > m.hi.Len() {
		return float64(m.lo[0])
	}
	return float64(m.lo[0]+m.hi[0]) / 2.0
}

type RandomizedSet struct {
	idx  map[int]int // 值 -> 它在 vals 里的下标
	vals []int       // 底层数组，随机取样直接下标命中
	rng  *rand.Rand  // 固定种子，让 demo 输出可复现
}

func (s *RandomizedSet) Insert(val int) bool {
	if _, ok := s.idx[val]; ok {
		return false
	}
	s.idx[val] = len(s.vals)
	s.vals = append(s.vals, val)
	return true
}
func (s *RandomizedSet) Remove(val int) bool {
	i, ok := s.idx[val]
	if !ok {
		return false
	}
	last := s.vals[len(s.vals)-1]
	s.vals[i] = last
	s.idx[last] = i
	// 顺序不能反：先写 idx[last] 再 delete(idx[val])，否则 last == val 时会漏删
	delete(s.idx, val)
	s.vals = s.vals[:len(s.vals)-1]
	return true
}
func (s *RandomizedSet) GetRandom() int { return s.vals[s.rng.Intn(len(s.vals))] }
func NewRandomizedSet(seed int64) *RandomizedSet {
	return &RandomizedSet{map[int]int{}, nil, rand.New(rand.NewSource(seed))}
}
func main() {
	c := NewLRUCache(2)
	c.Put(1, 1)
	c.Put(2, 2)
	g1 := c.Get(1)
	c.Put(3, 3)
	fmt.Println("0146 case1 get(1)/get(2) =", g1, c.Get(2))
	c1 := NewLRUCache(1)
	c1.Put(1, 100)
	c1.Put(2, 200)
	fmt.Println("0146 case2 容量 1 get(1)/get(2) =", c1.Get(1), c1.Get(2))
	c.Put(3, 33)
	fmt.Println("0146 case3 更新已有 key get(3)/get(1) =", c.Get(3), c.Get(1))
	s := &MinStack{}
	s.Push(-2)
	s.Push(0)
	s.Push(-3)
	mn := s.GetMin()
	s.Pop()
	fmt.Println("0155 case1 getMin / pop 后 top+getMin =", mn, s.Top(), s.GetMin())
	s.Push(-3)
	s.Push(-3)
	mn2 := s.GetMin()
	s.Pop()
	fmt.Println("0155 case2 重复最小值 / pop 后 getMin+top =", mn2, s.GetMin(), s.Top())
	s.Push(7)
	fmt.Println("0155 case3 再压大值 getMin/top =", s.GetMin(), s.Top())
	m := &MedianFinder{}
	var med []float64
	for _, v := range []int{1, 2, 3} {
		m.AddNum(v)
		med = append(med, m.FindMedian())
	}
	fmt.Println("0295 case1 add(1,2,3) ->", med)
	m1 := &MedianFinder{}
	for _, v := range []int{-5, -1, 0, 4} {
		m1.AddNum(v)
	}
	fmt.Println("0295 case2 负数与偶数个 ->", m1.FindMedian())
	m2 := &MedianFinder{}
	for _, v := range []int{10, 8, 6, 4, 2} {
		m2.AddNum(v)
	}
	fmt.Println("0295 case3 递减流 ->", m2.FindMedian())
	r := NewRandomizedSet(19)
	fmt.Println("0380 case1 insert(1)/insert(2)/getRandom/remove(1)/getRandom =", r.Insert(1), r.Insert(2), r.GetRandom(), r.Remove(1), r.GetRandom())
	r1 := NewRandomizedSet(19)
	fmt.Println("0380 case2 insert(7)/再 insert(7)/remove(9) =", r1.Insert(7), r1.Insert(7), r1.Remove(9))
	r1.Insert(20)
	fmt.Println("0380 case3 remove(7)/getRandom =", r1.Remove(7), r1.GetRandom())
}

5. 变体与边界 ​

  1. LFU 缓存：把「最久未用」换成「最少使用」，链表改成频率桶链表，命中时先解绑再入桶。
  2. 带过期时间的缓存：每个条目加 TTL，哈希表存到期时间，get 时顺手判断是否过期。
  3. 滑动窗口中位数：0480 要求能删除，两个堆必须加懒删除标记，否则堆顶可能是已删元素。
  4. 日程类接口：0729 用有序表在插入前查冲突，0732 用差分统计每个起点上的重叠数。

6. 常见错误 ​

  1. 淘汰了链表却忘了删哈希表：map 越滚越大，内存泄漏；两处必须同步。
  2. 辅助栈只在「更小」时才压：遇到重复最小值，真最小值被 pop 后辅助栈顶会过期。
  3. 两个堆方向搞反：下半区必须是大根堆，否则堆顶拿不到中位数。
  4. 删除后忘了改被搬元素的下标：map 里的下标与数组错位，随机取会取到重复值。
