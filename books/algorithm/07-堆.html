07 堆 ​

维护「当前最值」的容器：push/pop 是 O(log n)，取顶是 O(1)。 适合：Top K、第 K 大/小、流式最值、多路归并、任务调度。

1. 场景 ​

输入是一大串数字（分数、元素、任务），要求却只关心第 K 大、最大的 K 个，或者多路数据里当前最小的是谁。

决定性条件藏在约束里：0703 要每次 add 立刻返回答案；0023 的链表内部已有序；0215 的数组是静态的；0621 里同一任务要隔 n 格。

信号是「问排序后的第 K 个」或「反复问当前最值」，但不要求保序——允许排序时很多题排序了事，只有流式到来或多次查询时堆才不可替代。

2. 核心机制 ​

堆是只维护「堆顶是最值」这一条不变式的容器：container/heap 要求实现 Len/Less/Swap/Push/Pop 五个方法，Push/Pop 必须是指针接收者（它们要改切片本身），Less 决定方向（h[i] < h[j] 是小根堆，> 是大根堆）。

核心推导只有一句：第 K 大 = 最大的 K 个数里最小的那个。所以用容量固定为 K 的小根堆存住「目前最大的 K 个数」，堆顶就是第 K 大；容量多一个，堆顶就变成第 K+1 大，少一个则答案无从谈起。

同一个推导换个壳子就是多路归并：K 条有序序列，堆里每条只放一个当前候选，每次弹最小的再把它的后继补进去，弹出顺序天然全局有序。

操作堆里保留的 3 个数堆顶 = 第 3 大
初始 [4 5 8 2]4 5 84
add(3)4 5 8（3 被丢弃）4
add(5)5 5 85
add(10)5 8 105
add(9)8 9 108

3. 套路清单 ​

套路做法复杂度备注
第 K 大大小为 K 的小根堆，扫完取堆顶时间 O(n log K)，空间 O(K)静态数组可换快选，平均 O(n)
第 K 小大小为 K 的大根堆，扫完取堆顶时间 O(n log K)，空间 O(K)方向反过来，别搞混
流式最值固定容量堆，来一个挤掉一个每次 O(log K)，空间 O(K)每步都要答案，答案那端必须 O(1)
多路归并K 个有序序列各取一个候选入小根堆时间 O(N log K)，空间 O(K)弹出的节点要把后继补进堆
任务调度频率统计 + 帧长公式时间 O(n)，空间 O(1)公式已是最优，别硬上堆

4. Go 实现 ​

四道题共用一条主线：只维护当前最值。4.1–4.4 给的是片段实现，4.5 是可直接 go run 的完整程序。

4.1 0703 Kth Largest Element in a Stream（Easy） ​

题目要点：给 k 和一串分数，每 add 一个新分数就返回当前第 k 大（重复值各占一名次）。

教学实现

go
type intMinHeap []int // 小根堆：堆顶恒为当前最小值

func (h intMinHeap) Len() int           { return len(h) }
func (h intMinHeap) Less(i, j int) bool { return h[i] < h[j] }
func (h intMinHeap) Swap(i, j int)      { h[i], h[j] = h[j], h[i] }
func (h *intMinHeap) Push(x any)        { *h = append(*h, x.(int)) }
func (h *intMinHeap) Pop() any {
	old := *h
	v := old[len(old)-1]
	*h = old[:len(old)-1]
	return v
}

// KthLargest 只保留当前最大的 k 个数，堆顶恒为第 k 大。
type KthLargest struct {
	h intMinHeap
	k int
}

// Add 插入 val，返回当前第 k 大；堆顶就是答案。
func (kl *KthLargest) Add(val int) int {
	if kl.h.Len() < kl.k {
		heap.Push(&kl.h, val)
	} else if val > kl.h[0] { // 不比堆顶大就丢弃，它永远进不了 top-k
		heap.Pop(&kl.h)
		heap.Push(&kl.h, val)
	}
	return kl.h[0]
}

讲解：堆顶就是答案，所以方向必须是小根堆；容量固定为 k，多一个少一个答案就错位。堆没满时直接 push，满了以后只有比堆顶大的值才值得挤掉堆顶。构造函数 NewKthLargest 把初始值逐个喂给 Add，与后续插入同路径（见 4.5）。 Push/Pop 必须用指针接收者：它们要 append/截断切片本身，用值接收者等于改副本，堆顶根本不是最值。

4.2 0023 Merge k Sorted Lists（Hard） ​

题目要点：k 条升序链表合成一条升序链表，节点总数不超过 10^4，允许空链表。

教学实现

go
// MergeKLists 把 k 条升序链表合并成一条升序链表。
func MergeKLists(lists []*ListNode) *ListNode {
	h := &nodeHeap{}
	for _, l := range lists {
		if l != nil {
			*h = append(*h, l)
		}
	}
	heap.Init(h)
	dummy := &ListNode{}
	tail := dummy
	for h.Len() > 0 {
		cur := heap.Pop(h).(*ListNode)
		tail.Next = cur
		tail = cur
		if cur.Next != nil {
			heap.Push(h, cur.Next)
		}
	}
	return dummy.Next
}

讲解：nodeHeap 的五个方法与 4.1 的 intMinHeap 完全同构，只是元素类型换成 *ListNode、比较键换成 Val（完整定义见 4.5）。堆里始终只有 k 个候选，每弹出一个就把后继补进去，所以堆不会越滚越大，空间是 O(k)。 初始化必须跳过 nil 链表头，否则 Pop 之后解引用会 panic；dummy 节点则统一处理了「头节点」这个特例。

4.3 0215 Kth Largest Element in an Array（Medium） ​

题目要点：静态数组里求第 k 大，按排序后的名次算（重复值各占一名）。

教学实现

go
// FindKthLargest 返回 nums 中第 k 大的元素（k 从 1 开始）。
func FindKthLargest(nums []int, k int) int {
	h := &intMinHeap{}
	heap.Init(h)
	for _, x := range nums {
		if h.Len() < k {
			heap.Push(h, x)
		} else if x > (*h)[0] {
			heap.Pop(h)
			heap.Push(h, x)
		}
	}
	return (*h)[0]
}

讲解：沿用 4.1 的 intMinHeap。扫描时堆里始终是「目前最大的 k 个数」，扫完堆顶就是第 k 大；等于堆顶的值不替换，因为第 k 大按名次算、重复值各占一名。 题目只要平均 O(n)，那用快选（随机 pivot + partition）；堆是 O(n log k) 但最坏也稳，k 远小于 n 时更划算。

4.4 0621 Task Scheduler（Medium） ​

题目要点：同一任务两次出现至少隔 n 格，求排完所有任务的最少时间片数。

教学实现

go
// LeastInterval 返回完成所有任务所需的最少时间片数。
func LeastInterval(tasks []byte, n int) int {
	var freq [26]int
	for _, t := range tasks {
		if idx := t - 'A'; idx < 26 {
			freq[idx]++
		}
	}
	maxFreq, maxCount := 0, 0
	for _, f := range freq {
		if f > maxFreq {
			maxFreq, maxCount = f, 1
		} else if f == maxFreq && f > 0 {
			maxCount++
		}
	}
	frame := (maxFreq-1)*(n+1) + maxCount
	if frame > len(tasks) {
		return frame
	}
	return len(tasks)
}

讲解：最频繁的任务决定骨架：把它放在每帧开头，帧长 n+1，共 maxFreq-1 帧，末尾再放 maxCount 个同频任务，于是下界是 (maxFreq-1)*(n+1)+maxCount；任务多到把这个下界填满时不需要空闲，答案就是 len(tasks)，两者取大。 maxCount 只统计频率等于 maxFreq 的任务数——最容易写错的一步，f > 0 那个条件不能少：maxFreq 为 0 时不加上它就会数出 26 个「同频任务」。

4.5 完整可运行示例 ​

下面这份程序可直接 go run（只用标准库）。它包含本篇 4.1–4.4 的全部教学实现——代码与上面逐字一致（含注释）——以及覆盖全部用例的 main。

go
package main

import (
	"container/heap"
	"fmt"
)

type intMinHeap []int // 小根堆：堆顶恒为当前最小值

func (h intMinHeap) Len() int           { return len(h) }
func (h intMinHeap) Less(i, j int) bool { return h[i] < h[j] }
func (h intMinHeap) Swap(i, j int)      { h[i], h[j] = h[j], h[i] }
func (h *intMinHeap) Push(x any)        { *h = append(*h, x.(int)) }
func (h *intMinHeap) Pop() any {
	old := *h
	v := old[len(old)-1]
	*h = old[:len(old)-1]
	return v
}

// KthLargest 只保留当前最大的 k 个数，堆顶恒为第 k 大。
type KthLargest struct {
	h intMinHeap
	k int
}

// Add 插入 val，返回当前第 k 大；堆顶就是答案。
func (kl *KthLargest) Add(val int) int {
	if kl.h.Len() < kl.k {
		heap.Push(&kl.h, val)
	} else if val > kl.h[0] { // 不比堆顶大就丢弃，它永远进不了 top-k
		heap.Pop(&kl.h)
		heap.Push(&kl.h, val)
	}
	return kl.h[0]
}

// NewKthLargest 用初始流构造，初始值与后续 add 走同一条路径。
func NewKthLargest(k int, nums []int) *KthLargest {
	kl := &KthLargest{h: make(intMinHeap, 0, k), k: k}
	for _, v := range nums {
		kl.Add(v)
	}
	return kl
}

// ListNode 是链表的节点。
type ListNode struct {
	Val  int
	Next *ListNode
}

type nodeHeap []*ListNode // 按 Val 排序的小根堆，元素是链表节点指针

func (h nodeHeap) Len() int           { return len(h) }
func (h nodeHeap) Less(i, j int) bool { return h[i].Val < h[j].Val }
func (h nodeHeap) Swap(i, j int)      { h[i], h[j] = h[j], h[i] }
func (h *nodeHeap) Push(x any)        { *h = append(*h, x.(*ListNode)) }
func (h *nodeHeap) Pop() any {
	old := *h
	v := old[len(old)-1]
	*h = old[:len(old)-1]
	return v
}

// MergeKLists 把 k 条升序链表合并成一条升序链表。
func MergeKLists(lists []*ListNode) *ListNode {
	h := &nodeHeap{}
	for _, l := range lists {
		if l != nil {
			*h = append(*h, l)
		}
	}
	heap.Init(h)
	dummy := &ListNode{}
	tail := dummy
	for h.Len() > 0 {
		cur := heap.Pop(h).(*ListNode)
		tail.Next = cur
		tail = cur
		if cur.Next != nil {
			heap.Push(h, cur.Next)
		}
	}
	return dummy.Next
}

// FindKthLargest 返回 nums 中第 k 大的元素（k 从 1 开始）。
func FindKthLargest(nums []int, k int) int {
	h := &intMinHeap{}
	heap.Init(h)
	for _, x := range nums {
		if h.Len() < k {
			heap.Push(h, x)
		} else if x > (*h)[0] {
			heap.Pop(h)
			heap.Push(h, x)
		}
	}
	return (*h)[0]
}

// LeastInterval 返回完成所有任务所需的最少时间片数。
func LeastInterval(tasks []byte, n int) int {
	var freq [26]int
	for _, t := range tasks {
		if idx := t - 'A'; idx < 26 {
			freq[idx]++
		}
	}
	maxFreq, maxCount := 0, 0
	for _, f := range freq {
		if f > maxFreq {
			maxFreq, maxCount = f, 1
		} else if f == maxFreq && f > 0 {
			maxCount++
		}
	}
	frame := (maxFreq-1)*(n+1) + maxCount
	if frame > len(tasks) {
		return frame
	}
	return len(tasks)
}

// flat 把链表拍平成切片，方便打印与比较。
func flat(n *ListNode) []int {
	var out []int
	for ; n != nil; n = n.Next {
		out = append(out, n.Val)
	}
	return out
}

func main() {
	kl := NewKthLargest(3, []int{4, 5, 8, 2})
	fmt.Println("0703 题面示例 k=3 初始 [4 5 8 2] ->", kl.Add(3), kl.Add(5), kl.Add(10), kl.Add(9), kl.Add(4))
	kl2 := NewKthLargest(2, nil)
	fmt.Println("0703 边界 k=2 空流 ->", kl2.Add(7), kl2.Add(3))
	fmt.Println("0023 题面示例 [[1 4 5] [1 3 4] [2 6]] ->", flat(MergeKLists([]*ListNode{
		{Val: 1, Next: &ListNode{Val: 4, Next: &ListNode{Val: 5}}},
		{Val: 1, Next: &ListNode{Val: 3, Next: &ListNode{Val: 4}}},
		{Val: 2, Next: &ListNode{Val: 6}},
	})))
	fmt.Println("0023 边界 含空链表 [[] [1 2]] ->", flat(MergeKLists([]*ListNode{nil, {Val: 1, Next: &ListNode{Val: 2}}})))
	fmt.Println("0215 题面示例 [3 2 1 5 6 4] k=2 ->", FindKthLargest([]int{3, 2, 1, 5, 6, 4}, 2))
	fmt.Println("0215 边界 重复值 [7 7 7] k=1 ->", FindKthLargest([]int{7, 7, 7}, 1))
	fmt.Println("0621 题面示例 [A A A B B B] n=2 ->", LeastInterval([]byte("AAABBB"), 2))
	fmt.Println("0621 边界 单任务 [A A A A] n=2 ->", LeastInterval([]byte("AAAA"), 2))
}

5. 变体与边界 ​

  1. 静态数组的第 K 大：换成快选（随机 pivot + partition），平均 O(n)、最坏 O(n²)；数据是一次性的就没必要建堆。
  2. 流式中位数：两个堆——大根堆存小的一半、小根堆存大的一半，用 Push/Pop 在两堆之间搬运元素，维持两堆大小差不超过 1。
  3. 滑动窗口最大值：单调队列 O(n) 更优，堆是 O(n log n)。
  4. 真实调度：0621 的公式只求长度；要排出具体顺序就按（剩余次数、冷却时间）排序，用堆贪心。

6. 常见错误 ​

  1. 方向搞反：求第 K 大却用大根堆——堆顶是最大值不是第 K 大；第 K 大必须用小根堆。
  2. 用 heap.Fix(h, 0) 替换堆顶：Fix 只会往下沉，新值可能需要上浮，堆会被悄悄破坏；正确写法是 Pop + Push。
  3. Push/Pop 写成值接收者：Swap 改的是副本，切片不生效，堆顶根本不是最值。
  4. 堆没装满 k 就当答案：此时堆顶是见过的最小值，不是第 k 大；k 可以大于已见过的个数。
